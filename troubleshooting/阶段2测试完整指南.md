# 阶段 2 测试完整指南

## 问题诊断

你遇到的错误：
```
Package 'hydromining_robot' not found: "package 'hydromining_robot' not found, searching: ['/opt/ros/jazzy']"
```

**原因**：ROS 2 只在 `/opt/ros/jazzy` 中搜索，没有包含工作空间的 `install/` 目录。

## 常见错误与解决

### 错误 1：`deactivate：未找到命令`

**原因**：不在 Python 虚拟环境中

**解决**：忽略即可，或者如果在 venv 中，先 `deactivate`

### 错误 2：`install/setup.bash: 没有那个文件或目录`

**原因**：在错误的目录

**解决**：
```bash
pwd  # 确认当前目录
cd /home/star/SCI/hydromining_ws  # 切换到工作空间根目录
```

### 错误 3：`Package 'hydromining_robot' not found`

**原因**：未 source 工作空间环境

**解决**：
```bash
source install/setup.bash
ros2 pkg list | grep hydromining  # 验证
```

### 错误 4：Gazebo 启动但看不到机器人

**可能原因**：
1. URDF 解析失败
2. Mesh 文件缺失
3. Gazebo 插件未加载

**检查**：
```bash
# 查看日志
ros2 launch hydromining_robot robot_simulation.launch.py 2>&1 | tee launch.log

# 搜索错误
grep -i error launch.log
grep -i warn launch.log
```

### 错误 5：传感器话题无数据

**原因**：ros_gz_bridge 未运行或桥接失败

**检查**：
```bash
# 查看运行的节点
ros2 node list | grep bridge

# 查看桥接配置
ros2 node info /ros_gz_bridge
```

## 调试技巧

### 1. 分步启动

不使用 launch 文件，手动逐个启动：

```bash
# 终端 1：启动 Gazebo
gz sim src/hydromining_sim/worlds/coal_wall_v02.sdf

# 终端 2：发布机器人描述
ros2 run robot_state_publisher robot_state_publisher \
  --ros-args -p robot_description:="$(xacro src/hydromining_robot/urdf/panda_with_water_gun.urdf.xacro)"

# 终端 3：生成机器人到 Gazebo
ros2 run ros_gz_sim create -topic robot_description

# ... 依次启动控制器和桥接
```

### 2. 检查 URDF

```bash
# 验证 URDF 语法
cd /home/star/SCI/hydromining_ws
source install/setup.bash
xacro src/hydromining_robot/urdf/panda_with_water_gun.urdf.xacro > /tmp/robot.urdf
check_urdf /tmp/robot.urdf
```

### 3. 查看 TF 树

```bash
ros2 run tf2_tools view_frames
# 生成 frames.pdf
evince frames.pdf  # 查看 TF 树图
```

### 4. 录制调试数据

```bash
ros2 bag record -a -o debug_bag
# Ctrl+C 停止

# 回放
ros2 bag play debug_bag
```
