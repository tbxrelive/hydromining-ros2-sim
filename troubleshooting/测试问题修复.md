# 测试问题修复

## 问题诊断

你在错误的目录下运行命令：
```bash
(venv) star@star-A:~/SCI/hydromining_ws/src/hydromining_sim/scripts$
```

应该在工作空间根目录：
```bash
cd /home/star/SCI/hydromining_ws
```

## 正确的测试流程

### 1. 启动仿真

```bash
# 确保在工作空间根目录
cd /home/star/SCI/hydromining_ws

# 退出虚拟环境（如果在 venv 中）
deactivate

# Source ROS 2 环境
source install/setup.bash

# 启动仿真
ros2 launch hydromining_robot robot_simulation.launch.py
```

### 2. 测试机器人运动（新终端）

```bash
cd /home/star/SCI/hydromining_ws
source install/setup.bash
ros2 run hydromining_robot test_motion.py
```

### 3. 查看传感器数据（新终端）

```bash
cd /home/star/SCI/hydromining_ws
source install/setup.bash

# 等待几秒让仿真完全启动后再检查
ros2 topic hz /hydromining/camera/color/image_raw
ros2 topic hz /hydromining/lidar/points
ros2 topic echo /joint_states --once
```

## 如果仍然失败

### 检查构建

```bash
cd /home/star/SCI/hydromining_ws
colcon build --packages-select hydromining_robot
source install/setup.bash
```

### 检查包是否安装

```bash
ros2 pkg list | grep hydromining
# 应该看到：
# hydromining_robot
# hydromining_sim（如果构建了）
```

### 检查 Launch 文件

```bash
ros2 launch hydromining_robot --show-args robot_simulation.launch.py
```
