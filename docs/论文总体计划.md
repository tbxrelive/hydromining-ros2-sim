# 大论文总体实施计划（先出论文 A，再出论文 B）

## Context

**为什么要做这份计划**
1. **代码乱**：多轮会话（含 Codex）层层叠加，同时存在：
   - 3 套蚀除实现、4 套互不一致的可见性模型；
   - v1/v2/v3 三种观测编码、legacy/potential 两种奖励、20 cm/40 cm 两套任务分支；
   - `test_scripts/` 约 65 个文件，库、验收器、实验、调试脚本混在一起；
   - `results/` 61 G，其中 51 G 是 RL replay 缓存。
2. **RL 不是"调参不行"，而是奖励写错了**：
   - 12 个模型（DDPG/示范 DDPG/TD3/SAC × 3 种子）L0 成功率全为 0，规则基线为 0.92；
   - TD3 学到的是"在边缘反复短喷直到打穿"，回合回报 −17，反而比规则达标的 −33 更高。
3. **RL 的作用场景还没立住**：
   - 现在煤体均质、参数已知、无噪声，"找最大缺口喷"的规则几乎就是最优；
   - 这种条件下任何 RL 都很难超过规则，审稿人会问"为什么要用 RL"。
   - **这不是说不用深度强化学习**。研究内容 (4) 要求"结合规则与 DRL"，所以要把环境改成 RL 真正有用的条件：煤体非均质、强度未知、喷后反馈有噪声。结构上采用"规则先验 + 残差 RL"。见第五节第 5 章与第七节阶段 6。
4. **NBV 方法和效果都偏弱**：
   - 当前是通用体积信息增益，属 Isler ICRA 2016 一类，已经饱和；
   - 3 个基线视点几乎覆盖全区，补看增益很小（实测 99.68%→100%）；
   - 没有考虑机械臂运动代价。
5. **还没做查重式文献梳理**：需要确认我们的做法没有和已有工作重合。

**目标**
- 按**大论文章节**重建实验体系。每个实验有编号、统一接口、统一结果格式，可以随时看出做到了哪一步。
- 代码按章节归位，清理杂乱文件。
- 先投论文 A（机器人方向英文 SCI：感知 + NBV），再投论文 B（煤炭学报：自适应喷射决策），最后整合大论文。

**主线**：任务达标置信度判决。
- 判据：δ − kσ ≥ 5 cm 的面积 ≥ 90%（δ 为退缩量，σ 为其不确定度）。
- 输出三分类：achieved / not_achieved / insufficient_evidence。
- 这条判据贯穿感知、观测、决策三部分：
  - 感知给出 δ 和 σ；
  - NBV 去降低"影响判决结论"的那部分不确定性；
  - 喷射决策去补置信下界上的缺口。

**本计划已于 2026-11-01 经用户批准**，存为 `docs/论文总体计划.md`。按第七节顺序执行，每个阶段开始前再与用户确认。

### 1.3 查重结论

1. **"机械臂水力破煤 + 感知效果闭环"整体**：SCI 中未检索到，属于应用层面的空白，最有说服力。前提是知网复核也确认没有。
2. **NBV 创新点必须是组合式的**，单独任何一项都已有人做过：
   - 运动代价：Naazare 2022；
   - 任务导向：Biosystems Eng 2024；
   - 传感器退化感知：FRA-NBV 2026。
   - 可以成立的表述是"**面向阈值判决验证**的信息价值 + **自身喷射动作诱发的动态水雾**干扰预测 + 运动代价 + 序贯停止"，并在论文 A 中对这三类工作逐一做对比实验或讨论。
3. **RL 创新不能写成"材料随机化 + RL"**，这已经有了（Egli 2022、RA-L 2023）。可以成立的是：
   - 以**感知置信判决作为反馈和终止信号**；
   - 用规则做先验，RL 学残差；
   - 加防贯穿安全护盾；
   - 面向破煤工艺。
4. **Yan & Li RCIM 2027 和 Zhang 2026 Appl. Sci. 是最需要细读全文的两篇**，需要你从学校数据库下载 PDF 放进 `docs/文献/`。

## 五、各章实验设计

### 第 2 章　仿真系统（E2）
- **E2.1 破煤模型文献标定**：把 `DefaultErosionKernel` 的压力、靶距、时长三类响应与 1.2 节的破煤文献对比，给出参数依据，并做敏感性分析（OAT 或 Sobol）。
- **E2.2 非均质、强度未知的煤体**：在 R_c 上乘一个空间随机强度场（对数正态 + 相关长度 + 硬块夹矸），每个回合随机生成，策略看不到。L0 和 Level Set 共用这个场。
- **E2.3 统一干扰等级**：无/低/中/高 × 正常/昏暗，复用阶段 5 的粒子和阶段 6 的 `environment.py`。
- **E2.4 多保真度一致性**：重跑 fidelity benchmark，确认加入非均质场后 L0 与 Level Set 仍一致。

### 第 3 章　感知与效果评估（E3，论文 A 前半）
**创新点 1**：动态喷射干扰下的多帧双传感器融合，加区域置信下界三分类判决。与 M3C2-EP 和矿用除尘方法对比，卖点是强干扰下不虚报达标。
- **E3.1 重建精度**：干扰等级 × 测试墙面 × 初始工况，统计 RMSE、P95 误差和有效覆盖率。
- **E3.2 消融与对比**：去掉时序滤波、只用相机、只用 LiDAR、去掉 σ（改为固定阈值判决），再加单帧统计滤波基线。
- **E3.3 判决可靠性**：三分类混淆矩阵、误达率、σ 校准（区间覆盖率是否接近名义的 95%）。σ 校准是阶段 6 的遗留项，必须补上。

### 第 4 章　主动观测规划（E4，论文 A 后半）
**创新点 2**：面向阈值判决验证的主动视点规划。由四部分组成：
1. **判决导向增益**：每个单元的模糊度定义为 |δ − d_req|/σ。只有置信区间跨过阈值、且会影响 90% 面积判决的单元才计分；已经确定在阈值以上或以下的单元，即使 σ 大也不计分。打分时复用 `expected_sigma` 和 `observed_visibility`。
2. **自身喷射诱发的动态干扰预测**（用户已确认纳入）：
   - 沿视线积分水雾和粉尘密度场，复用 `sensor_model.transmittance/degrade_ranges`；
   - 密度场只由可观测量在线估计：喷射状态、已过时间、`interference_filter.foreground_mask` 的剔除率；
   - 与 FRA-NBV（静态反射率）的区别在于干扰随我们自己的动作而动态变化。
3. **运动代价与约束**：新建 `motion_cost.py`，用 `kinematics.Chain` 做 IK，代价为关节空间运动时间，同时剔除不可达和近墙的视点。候选视点由 `make_viewpoints.py` 做半球采样批量生成。
4. **序贯停止规则**：误判概率低于 ε 时停止；"单位运动代价的预期判决价值"低于阈值时，停止并报 insufficient_evidence。

**实验条件要让 NBV 有发挥空间**：初始只有 1 个视点、60° 墙面加深坑自遮挡、中/高干扰、视点预算受限。
- **E4.1 方法对比**：固定视点 / 随机 / 体积信息增益（Isler）/ 体积信息增益 ÷ 运动代价（Naazare 式）/ 本文方法。指标：判决正确率、误达率、视点数、运动时间、insufficient_evidence 比例。
- **E4.2 干扰鲁棒性**：喷射过程中和喷后消散期分别观测。
- **E4.3 消融**：逐个去掉判决加权、干扰模型、运动代价、停止规则。
- **E4.4 干扰模型验证**：在 Gazebo 中用阶段 5 粒子场景，对比预测与实测的有效回波比例。
- 批量实验在 L1/L2 上跑，每组 ≥ 30 回合，做配对检验；抽样在 Gazebo 中复核。

→ **E3 + E4 完成后写论文 A。**

### 第 5 章　自适应喷射决策（E5，论文 B）
**RL 的定位**：不是去掉 RL，而是让 RL 解决规则解决不好的问题。具体是：煤体强度未知且不均匀时，规则按固定模型估算时长会过喷或欠喷；RL 依据"喷后感知判决反馈"在线修正。

分步推进，每一步都有可检验的结论，你可以边做边学：
- **E5.0 修奖励（冒烟）**：
  - 打穿算失败，惩罚要大于任何回合可能的累计成本；
  - 达标奖励要大于典型的喷射成本；
  - 用几千步 L0 冒烟确认策略不再收敛到 [-1,-1,-1] 的打穿捷径。
- **E5.1 均质煤体重训 DDPG/TD3/SAC**：回答"之前失败是不是只因为奖励"。预期结果接近规则，这本身就说明了为什么需要 E5.2。
- **E5.2 非均质、强度未知煤体（E2.2）**：对比规则、模型贪心、纯 DRL。
- **E5.3 创新点 3：规则先验残差 RL + 防贯穿安全护盾**：
  - 动作 = 规则动作 + 有界残差；
  - 护盾按预测退缩量和剩余厚度裁剪喷射时长；
  - 用规则示范做离线预热；
  - 观测编码由 3756 维平铺向量改为小 CNN；
  - 算法选 SAC 或 TD3（DDPG 只作为对照）。
- **指标**：完成率、误达率、耗水、能耗、喷射次数、作业时间、贯穿率。在初始工况 × 强度场种子上每组 ≥ 30 回合，≥ 3 个训练种子。
- 与 Egli 2022、Shin 2025、Yan & Li 2027、Zhang 2026 逐一做区分讨论。

→ **E2 + E5 完成后写论文 B（煤炭学报）。**

### 第 6 章　闭环（E6，大论文）
- 在 Gazebo 中对比三组：本文 NBV + 残差 RL / 体积信息增益 + 规则 / 固定视点 + 规则。
- 报告完成率、总时间、耗水，并录制 GUI 演示视频。
- 复用 `phase7_real_loop.py`，改为调用统一接口。
