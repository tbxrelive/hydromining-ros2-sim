# 感知效率、喷射决策与GUI退出调查（2026-10-30）

## 本次用户运行的可核实结果

- 本轮GUI入口默认tri_r5，先完成3个预设喷射再由规则决策。5次决策喷射（7.0、6.2、6.0、5.3、4.0秒，共28.5秒），然后收尾；完整墙钟时间约9分56秒，包含启动、预喷、基线与观测，不可作为单次喷射耗时。
- 运行实际目标：直径0.2m的局部区域，90%面积的退缩不小于0.02m；置信下界91.21%，独立网格核对97.15%。没有覆盖整面3×3m煤壁的采掘目标、作业分区、推进规则或可靠的总时间估计。
- 缺口定义 `required_depth + confidence_k * sigma - delta`：20.6mm是目标区域最差有效单元还需补足的保守深度，不是单发喷深。该次模型服务记录的单次最大退缩47.55mm、移除体积约265.6cm³，它们是最大值与总体体积，不能当作目标区域均匀退缩或真实试验。
- 每次真实喷射使用固定压力20 MPa，真实执行时长上限8s，靶距规则名义值0.7m；蚀除速度的压力、距离响应采用临时工程公式，未实验标定，不能判断该水压在实际煤层是大还是小。DDPG当前不输出压力。
- 当前CLI默认RulePolicy。达标→finish；证据不足且候选视点有收益时→NBV补看；否则选保守缺口最大单元，以 `clip(6s × 缺口 / 20mm, 2s, 8s)` 给时长。只有传 `--model` 才把已训练模型加载为喷射位置/时长策略，模式与NBV仍是规则；无模型本次没有DDPG推理，更没有使用已训练模型。

## 当前算法与耗时

传感器RGB-D和LiDAR通过实际TF对齐，视点3个、每点3帧；距离和传感器误差模型驱动时域过滤、前景剔除，墙面坐标系0.5m范围/1cm分辨率2.5D高度栅格；格内中位数/MAD去离群，支持时用加权局部平面，格间跨帧Huber/逆方差融合，保留系统误差下限与未知区。喷前基线与喷后图比较，用置信区间计算体积与达标面积三分类。不是当前在线用ICP做每次配准，也不是全3D TSDF或神经网络感知。

真实日志的一个示例：喷射完成至3个观测位姿最后到达约20.8s（每段约5s，含间隔）；最后到达至评估完成28.8s（混合后续采样等待和数据处理，未独立测出每项）；评估完成到下一段运动3.5s（含可见性、决策等，不是纯决策计时）。感知链路是主要可见瓶颈，精确瓶颈须细分profiling后确定。主流程每次喷后重建当前图，补看 `observe()` 将先前和新帧合并后重新build_map；减少重复有候选价值，但喷射改变表面，不能把喷前数据直接当喷后的新证据。

## 开源参考与适配判断

- [Open3D 0.19点云滤波/体素降采样](https://www.open3d.org/docs/release/tutorial/geometry/pointcloud_outlier_removal.html)：ROI裁剪和体素降采样可缩小点数；需要比较小凹坑几何误差、覆盖、噪声及误判，不能先假设降采样仍满足2cm判据。
- [RTAB-Map ROS 2组件](https://github.com/introlab/rtabmap_ros/blob/ros2/rtabmap_util/README.md)：将传感器路径组件组合可避免不必要的数据拷贝，地图装配可移出关键路径。可借鉴数据流与增量更新思想，固定机械臂已知TF的局部任务不应直接替换成复杂SLAM。
- [voxblox](https://github.com/ethz-asl/voxblox) CPU TSDF/ESDF；[NVIDIA nvblox](https://github.com/nvidia-isaac/nvblox) GPU TSDF/ESDF。适合按需比较大规模三维重建，不等价于本项目已验证的2.5D置信评估，也不会缩短5秒机械臂运动。
- 硬件兼容要先验证：TITAN V是Volta。NVIDIA Isaac ROS [3.1文档](https://nvidia-isaac-ros.github.io/v/release-3.1/getting_started/hardware_setup/compute/index.html)支持Volta；[3.2文档](https://nvidia-isaac-ros.github.io/v/release-3.2/getting_started/hardware_setup/compute/index.html)要求Ampere及以上。新版[Jazzy Nvblox](https://nvidia-isaac-ros.github.io/v/release-4.6/repositories_and_packages/isaac_ros_nvblox/index.html)列为Ampere以上，不能宣称本机四张TITAN V可直接跑当前版本。ROS版本、CUDA/驱动、构建架构需隔离验证，不修改现有稳定环境。

2. **优先减少机械移动与重复数据**：比较现有3视点×3帧、较少视点/帧及不确定时NBV补看的策略。对遮挡、重干扰和证据不足自动回退到完整观测；对同一喷后轮累计补看做真正增量融合，并验证等价和取消/并发安全，喷射后失效受影响的观测。

4. **验收及回归**：旧/新方案同样数据与种子对照单轮总耗时、各阶段耗时、覆盖、几何误差、面积上下界、漏检/误达、取消和资源；六真实工况和粒子/noise回归、喷后真实真值离线核对；记录中位/P95和误差，以实测定优化目标，不提前承诺倍速。
5. **喷射压力和整墙目标另行定义**：不盲目调大压力。提供模型压力/靶距/喷射时长扫描和可视化，保留未标定标记；若目标是大范围采掘，先明确采掘深度、覆盖区域、作业路径与停止条件，再估算时间。DDPG只在用户运行训练后按相同场景比较达标率、误达、喷射数/总时长、墙钟耗时及泛化，不能假定训练必然提速。
