## 4. 实际系统架构

基础层：Gazebo Harmonic 世界与煤壁模型；Panda 七自由度机械臂、水枪、TCP、末端 RGB-D 与固定式 LiDAR；gz_ros2_control 驱动关节轨迹控制器；ros_gz_bridge 桥接图像、点云、时钟。

喷射层：网格 → 负内正外三角形距离 SDF → 压力/当前靶距相关的径向冲蚀核与暴露掩码 → Godunov 迎风 Level Set 演化 → Marching Cubes → Gazebo 模型事务替换。独立效果插件显示水柱、飞溅及水雾粉尘。

感知层：准确时间戳 TF、静止多帧过滤、初始参考法向、双传感器 2.5D 高度融合、不确定性估计、喷前喷后变化与有效观测体积、三分类判决。TSDF 和 M3C2EP 是辅助交叉核验路径，不能把它们描述为主判决流程。

决策层：NBV 候选视点评分、缺口驱动规则喷射、达标收尾；替身 L1/L2 环境与 Gymnasium/SB3 DDPG 训练脚本。真实循环经 AssessRegion Action 与 SprayAction 服务执行。

作业要求：直径 20 cm 区域中，至少 90% 面积沿固定初始法向退缩不小于 2 cm。已知单元按 delta±k·sigma 构造面积上下界；未知区域不直接计为达标。下界达到 0.9 才 achieved，上界低于 0.9 为 not_achieved，其余 insufficient_evidence。当前 uncertainty_calibrated 明确为 false，因此不是已经实测校准的统计保证。
