# 代码模板库 (Codebook)

本目录包含项目常用的 ROS 2 代码模板，遵循 **鱼香ROS代码规范**。

## 📚 规范文档

- **完整规范**: [`../鱼香ROS代码规范总结.md`](../鱼香ROS代码规范总结.md)
- **外部技能库**: [`../../robotics-agent-skills/`](../../robotics-agent-skills/)

## 📂 模板分类

| 目录 | 用途 | 示例 |
|------|------|------|
| `rclpy/` | Python ROS 2 节点模板 | 生命周期节点、服务客户端 |
| `launch/` | Launch 文件模板 | 参数传递、条件启动 |
| `config/` | 配置文件模板 | YAML 参数、控制器配置 |

## 🎯 使用指南

1. **选择模板**: 根据任务类型选择对应目录
2. **复制修改**: 复制模板文件，按需修改类名/话题名
3. **遵循规范**: 保持命名约定、文档字符串、日志格式

## ⚙️ 开发原则

- ✅ 算法与 ROS 通信分离
- ✅ 使用生命周期节点 (Lifecycle Node)
- ✅ 声明 QoS 配置文件
- ✅ 完整的文档字符串
- ✅ 日志记录关键事件
