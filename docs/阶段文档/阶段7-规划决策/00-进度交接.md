## 2026-10-28 更新（7.4 L1 快速通道 + DDPG v1 训练诊断）

### L1 替身（批量训练用，与 L2 同构评估）

- `_l1_build_map`：truth_heights 取表面 -> 每视点每格带噪融入 HeightMap；**不走全分辨率渲染/时序融合**，评估仍走 `compare_surfaces`+`assess` 同一三分类。
- **计数语义修正**：每视点 3 帧（`L1_FRAMES_PER_VIEW=3`）对齐真实管线 `frames_per_view`，否则单视点覆盖单元永远达不到 `minimum_observations=2`（规则层曾因此无限补看）。
- **可见性 = 相机∪LiDAR**：`_l1_sensor_mask` 按传感器分别算视场+遮挡，掩码并集进图。**这是"已达标"工况可验证的关键**——VLP-16 位姿能看进深度相机被坑沿遮住的坑底（纯相机模型下 dense 覆盖率仅 6%，并集后判决 achieved 0.99，与真实双传感器系统一致）。
- **工况缓存**：蚀除确定性 + 固定参考系 -> `_episode_cache` 按工况缓存预喷 phi/表面/掩码，`world.restore()` 直接恢复；热 reset ~0.35s（原 10-30s）。
- 实测吞吐：L1 ~2 步/s（4 并行 ~3.4 步/s 热身期后）、单步喷射 ~1.3s（64 网格）；L2 单步 ~8s。

### 已修复的语义缺陷

- `pristine_` 此前在 `apply_scenario` **之后**采样——"已达标"工况收尾会被误判 not_achieved；已改为预喷**前**取真值基线。
- 终局奖励曾把"诚实报告未达标"也发 +10 -> 20k 步策略学会第 1 步直接收尾。改为：**判决+真值双达标 +10；虚报达标 -10；其余按置信下界缺口比例罚**（截断同口径）。
- 规则缺口图改用判决准则 `required_depth + k·σ − δ`（原名义阈值漏喷置信带跨界单元）-> L1 规则基线 6/6 achieved、L2 替身 single/tri_r5 复验 achieved。

### DDPG v1 结果与诊断（重要）

- 20k 步/4 并行 L1 full 模式（[observe,spray,finish]argmax + 7视点argmax + u,v,dur）训练完成，**策略塌缩为固定 observe front_0p6×12，从不喷射**。
- 根因：critic 在原始连续向量上学 Q，奖励由 argmax 解码语义决定；向量内扰动不改变解码动作 -> Q 曲面平台化 -> actor 拿不到模式梯度。这是混合离散-连续动作用裸 DDPG 的已知失效（正解是 P-DQN 类参数化动作，SB3 未提供）。
- **v1 交付范围调整**：DDPG 聚焦纯连续子问题 `action_mode='spray'`（动作=(u,v,duration) 三维），模式/视点选择留规则层——对应"自适应喷射"需求本体；混合动作空间留作 TD3/SAC/P-DQN 后续。
- spray 模式语义：判决 achieved 自动收尾（同规则层，不耗动作）；`dense` 首步 +10 已验证。
- `test_scripts/phase7_evaluate.py`：random/rule/DDPG 三策略同工况对照（rule 适配层可见性用真实掩码——均匀掩码会导致预测增益不可兑现的死循环）。

- **真实 `single` PASSED**：10 步、下界 0.922 → achieved。边缘格连续三喷缺口卡在 16mm（弹坑自遮挡，与 L1 同一物理），但整体下界仍收敛。
- **真实 `pair` PASSED**：15 步、下界 0.910 → achieved。期间暴露并修复两个决策层缺陷：
  1. `KeyError: front_0p6`——`Phase7Loop` 只把 3 个基线视点传进决策层，NBV 选中扩展候选时取不到关节角。改为传入**全部可达候选视点**。
  2. `accumulated viewpoints exceed budget`——感知会话 `maximum_views=8` 是硬资源边界（config `__post_init__` 拒绝更大值），每轮补看预算 = 8 − 3 基线 = **5**。原规则层无计数：连看同一视点（front_0p6 ×3）直接撞顶。
- **决策层修复（decision.py，语义修正非参数调整）**：
  - `observed_views_` 记录本轮已补看视点，候选掩码置零——同一轮重复观测无信息增益，不应再选；
  - 喷射/收尾清空（喷射后是新观测轮次）；
  - `observe_budget=5` 每轮补看硬上限，与管线 `maximum_views` 对齐；预算耗尽落到喷射/收尾并在理由中注明；
  - `reset_episode()` 回合复位（截断回合不经 finish 清空）；两个闭环脚本与评估适配层已接入。
- **L2 替身 6/6 全 achieved 复验通过**（预算受限后仍收敛，empty 8 步 → dense 1 步，真值一致）。
