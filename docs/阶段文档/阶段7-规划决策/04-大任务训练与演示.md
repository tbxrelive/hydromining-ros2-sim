# 40 cm 任务：训练与演示

新任务采用相对水平面 60° 的煤壁、30 MPa、直径 40 cm 的作业区，以及 90% 面积退缩 5 cm 的收尾条件。压力、喷嘴和蚀除响应均为未标定的工程模型。

## 用户自行执行正式训练

```bash
cd /home/star/SCI/hydromining_ws
source setup_env.sh
.venv_rl/bin/python test_scripts/phase7_training_jobs.py --output results/phase7_training_large
```

入口先采集训练划分的规则示范，然后调度 DDPG、示范辅助 DDPG、TD3 和 SAC。默认各 3 个种子，每个种子先到 15000 步，再续到 50000 步；GPU 1 执行两组 DDPG，GPU 2 执行 TD3，GPU 3 执行 SAC，GPU 0 保留给桌面。每个作业使用两个 CPU 环境。运行完成后分别进行 L0、L1、L2 测试并生成 `comparison.json`；L1/L2 使用 5 mm Level Set，可能花很长时间。命令重新执行时会尝试从已有检查点恢复。

开始前会核对 `results/phase7_large_task/fidelity_release_v2/fidelity.json` 与当前模型代码的签名。若模型或任务配置发生变化，需重新运行完整精度测试；未通过时不允许正式训练：

```bash
.venv_rl/bin/python test_scripts/phase7_fidelity_benchmark.py --output results/phase7_large_task/fidelity_release_v2
```

训练结果按实际初始状态分别比较需要作业和初始已达标的工况。`comparison.json` 对成功率、误达次数、步数、喷射次数与总时长、移除体积、耗水、能耗、运行耗时及训练耗时列出种子均值和标准差；`fidelity_gap` 是 L0 减去 L1/L2 的均值差。用户已完成 12 个 50000 步模型的训练，部分高保真评估因异常中断，完整对照结论待评估完成。

高保真评估中若贯穿终止时任务区真值射线有缺失，该回合记为 `truth=unknown`，不填造退缩量或移除体积。`truth_unknown` 是未知回合数；成功率按全部回合计算，表示已证实成功的比例，不能把未知当成已证实失败。移除体积均值仅使用真值完整的回合，并记录有效回合数。

## Gazebo 演示

```bash
./scripts/run_gui_demo.sh
```

默认使用规则决策。完成训练后，可以指定某次训练的模型目录，例如：

```bash
./scripts/run_gui_demo.sh --model results/phase7_training_large/td3/seed_0
```

模型必须与当前任务及观测版本匹配；补看和收尾仍由规则层决定。Gazebo 浮动面板显示煤壁角度、作业区及目标、压力、流量、最近一次最大退缩、完成比例区间和决策状态，终端另外显示出口速度及各环节耗时。5 mm 几何求解及多视角感知耗时较长；规则闭环已达到感知与真值双重达标，最后的面板文字修改已通过真实单喷验证；四种短测模型已各执行一次真实 GUI 喷射。训练模型驱动的完整 GUI 尚未验收，运行状态以 `00-进度交接.md` 的最新记录为准。
