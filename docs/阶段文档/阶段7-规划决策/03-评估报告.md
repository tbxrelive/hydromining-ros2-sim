## 🔍 算法深度分析

### 1. 缺口图准则的重要性

**原错误定义**（已修正）：
```python
gap = required_depth - observed_depth  # ❌
```

**问题**：
- 忽略不确定性 σ
- 导致"置信下界已达标，但名义缺口仍大"的单元被误喷

**修正后**：
```python
gap = (required_depth + k * sigma) - observed_depth  # ✅
```

**效果对比**（tri_r5 工况）：

| 准则 | 喷射次数 | 最终下界 | 判决 |
|-----|---------|---------|------|
| 错误（名义） | 9 | 0.897 | insufficient_evidence ❌ |
| 正确（保守） | 7 | 0.921 | achieved ✅ |

**结论**：修正后规则层避免了"过度喷射已达标单元"，效率提升 **22%**。

### 2. 可见性掩码：相机 ∪ LiDAR

**关键发现**：纯相机模型在 dense 工况覆盖率仅 **6%**（坑底被遮挡）。

**修正后**（L1 替身）：
```python
def _l1_sensor_mask(view, sensor):
    if sensor == 'camera':
        # 深度相机：视场 + 深度范围
        mask = (angle < 60°) & (depth < 5m)
    elif sensor == 'lidar':
        # VLP-16：16 线 + 360° 扫描
        mask = ray_cast(view, lidar_rays)
    
    return mask

visible = camera_mask | lidar_mask  # 并集
```

**效果**：

| 工况 | 纯相机覆盖率 | 相机+LiDAR 覆盖率 | 提升 |
|-----|------------|----------------|------|
| dense | 0.06 | **0.99** | +1550% |
| tri_r5 | 0.82 | **0.99** | +21% |
| empty | 1.00 | 1.00 | 0% |

**结论**：LiDAR 对**深坑场景**至关重要（VLP-16 的倾斜扫描能看进坑底）。

### 3. L1 vs L2 替身权衡

| 维度 | L1 | L2 | 选择建议 |
|-----|----|----|---------|
| **吞吐** | ~2 步/s | ~0.12 步/s | 训练用 L1 |
| **保真度** | 中（无渲染） | 高（全渲染） | 验证用 L2 |
| **传感器** | 射线 + 噪声 | RGB-D + LiDAR | L2 更真实 |
| **蚀除** | Level Set（同） | Level Set（同） | 物理一致 |
| **工况缓存** | ✅ (~0.35s) | ❌ (10-30s) | L1 快速重置 |

**训练策略**：
1. L1 探索超参数（快速迭代，1-2 天）
2. L2 验证最优策略（高保真，数小时）
3. 真实 Gazebo 最终验收（物理引擎，数小时）
