# 阶段六设计方案：受干扰观测下的煤壁状态估计与作业判定

**状态**：**用户已批准并开始实施**，2026-10-28 正在推进 6.0。基础数据、原生噪声、坐标工具和离线背景退化子表已有验证；完整融合、重建、判决尚未完成。最新证据与实现边界见 `02-基础数据与噪声验证报告.md`、`03-离线环境退化数据验证报告.md`。两篇参考文献已纳入（第 11 节）；煤矿环境要求见第 12 节。  
**日期**：2026-10-26  
**环境**：ROS 2 Jazzy + Gazebo Harmonic；算法层为纯 Python（`.venv_stage4`，Open3D 0.20.0，Python 3.12）。

---

## 1. 目标

基于阶段五受水雾、粉尘干扰的深度相机与 LiDAR 观测，完成：

1. 数据时空对齐；
2. 干扰剔除与多传感器融合；
3. 煤壁表面重建：几何、局部法向、有效观测范围、逐点不确定性；
4. 喷射前后对比：识别真实破坏区域，估计退缩深度、有效观测区域内的移除体积（以及按 ρ_c 折算的质量）；
5. 对指定作业区域给出三分类判决：**达到作业要求 / 未达到 / 证据不足**；
6. 通过 ROS 2 接口为阶段七提供状态图与判决结果，并让算法层可以被阶段七的强化学习训练环境直接调用。

**"真实破坏区域"的含义**：本阶段指**几何上可观测的材料去除**（表面退缩）。参考文献二表明，破碎坑周围还有径向、环向裂纹和更大范围的拉伸损伤区，这些不会改变表面几何，深度相机和 LiDAR 测不到，当前仿真也不会渲染裂纹，因此无法验证。裂纹和损伤区识别不计入本阶段完成内容，作为适用边界写明。

不在本阶段范围内：主动选择视点（NBV）、喷射参数决策（归阶段七）；破煤模型参数标定（阶段四遗留项）；修改阶段五的已有实现（只在第 9 节记录需要注意的地方）。

## 3. 作业要求的形式化（用户 2026-10-26 设定）

> 在预先划定的直径 20 cm 区域内，至少 90% 的面积，相对本轮任务开始前的煤壁表面，沿约定的局部法向退缩不少于 2 cm。

为了能够计算，补充以下约定（建议作为默认值，全部可以通过参数修改）：

| 符号 | 默认值 | 约定 |
|---|---|---|
| 区域中心 c | 任务给定 | 任务开始前在 world 坐标系中固定，之后不随观测结果改变 |
| 直径 D | 0.20 m | 区域定义为以 c 为中心、在墙面坐标系 (u, v) 平面上的圆 |
| 约定法向 n | 自动计算 | 任务开始前，对区域及其外扩 5 cm 范围内的基线表面做稳健平面拟合，取其法向；整轮任务固定不变（不用逐点法向，避免噪声影响判决） |
| 深度阈值 h | 0.02 m | 沿 n 的退缩量 Δd = 基线位置 − 当前位置（朝煤体内部为正） |
| 面积比例 p | 0.90 | |
| 置信系数 k | 1.645 | 单侧 95% |

**三分类判决（区间界方法）**：设区域面积为 A，单元格面积为 a_i，未观测面积为 A_unobs。

- 保守下界 F_low = Σ_已观测 a_i · 1[Δd_i − kσ_i ≥ h] / A（未观测部分全部按"不合格"计）
- 乐观上界 F_high = (Σ_已观测 a_i · 1[Δd_i + kσ_i ≥ h] + A_unobs) / A（未观测部分全部按"合格"计）
- F_low ≥ p → **达到**；F_high < p → **未达到**；其余情况 → **证据不足**。

这个规则能自然处理覆盖不全的情况：即使有部分未观测，只要结论已经确定，仍然可以判定；结论不确定时，输出"证据不足"，同时给出缺证据的位置，作为阶段七选择视点的输入。σ_i 中包含配准误差这类共模项，计算是偏保守的。

真值类别用同一规则计算，但使用真值网格的精确 Δd、σ = 0、无未观测区域。

## 4. 总体架构

```
Gazebo（阶段五环境，干扰与噪声开关可配置）
   │  深度图 + 相机内参 / LiDAR 点云 / TF / 仿真时钟
   ▼
wall_perception_node（生命周期节点，ROS 适配层）
   │  按传感器时间戳查 TF → numpy 数组
   ▼
algorithms/perception/（纯 Python，不依赖 ROS）
   frames → sensor_model → interference_filter → height_map (+ tsdf_mesh)
          → change_detection → assessment → metrics（仅评估时使用，读取真值）
   ▼
AssessRegion Action 结果 + CoalWallState 状态图消息 → 阶段七
```

- **主表示：墙面坐标系下的 2.5D 高度图。** 墙面坐标系由基线观测做全局平面拟合得到，不读取真值位姿。每个栅格存：深度均值、方差、观测次数、干扰剔除比例、法向、最后观测时间。单元格大小默认 1 cm。
- **辅助表示：Open3D VoxelBlockGrid TSDF。** 用于输出网格、可视化，以及和高度图交叉校验。
- **适用边界：** 2.5D 表示不能描述倒悬或掏空形状。目前凹坑约 6 cm 深，没有问题；如果发现某个单元格同一条射线上出现多个表面，就标记为"超出 2.5D 适用范围"，按"证据不足"处理。

## 5. 算法模块

位置：`src/hydromining_sim/scripts/algorithms/perception/`（沿用现有 `algorithms/` 的组织方式）。

| 模块 | 职责 | 关键方法 |
|---|---|---|
| `frames.py` | 墙面坐标系、区域定义、坐标变换 | 稳健平面拟合（RANSAC 加 PCA）；(u, v, d) 参数化 |
| `sensor_model.py` | 每次测量的 σ | 深度相机：σ = σ0 + k_z·z²，再除以入射角余弦修正；LiDAR：常数测距误差加角度项。参数取自器件规格书，并在参数文件中注明来源 |
| `interference_filter.py` | 干扰剔除 | 粒子只会出现在煤壁前方：逐射线计算相对当前地图的残差，残差显著为负的判为遮挡；多帧时序中位数和 MAD；失效点统计；输出逐点权重 |
| `height_map.py` | 融合 | 逐格按逆方差加权，并做 Huber 稳健更新；局部平面拟合得到法向；覆盖状态分三类：可靠 / 不足 / 未观测 |
| `tsdf_mesh.py` | 网格重建 | Open3D VoxelBlockGrid 积分深度图并导出网格 |
| `change_detection.py` | 前后对比 | 逐格计算 Δd 与 σ_Δ = √(σ_基线² + σ_当前² + σ_配准²)；用 py4dgeo M3C2-EP 做点云层面的交叉校验；体积 V = Σ Δd·a 及其方差；质量 m = ρ_c·V |
| `change_detection.py`（续） | 区域外意外变化 | 在整个已观测墙面上标记显著变化，报告作业区域**外**的显著退缩（对应文献二中沿层理劈裂、块体剥落造成的不连续大面积变化），作为单独的告警字段输出，不并入作业区域的判决 |
| `assessment.py` | 判决 | 第 3 节的区间界方法；输出 F_low、F_high、覆盖率、缺证据单元格列表 |
| `metrics.py` | 评估（只在测试中使用） | 对真值网格做光线求交；计算表面 RMSE、法向角误差、置信区间覆盖率、体积误差、混淆矩阵 |

**配准原则（来自参考文献的启发）：** 喷射前后的对齐只能使用**未被喷射的稳定区域**，或者直接使用 TF。不能用整面墙做 ICP，否则大面积均匀退缩（论文中观察到的"分层剥落 / 新表面"破坏形态）会被配准误当成位姿偏差吸收掉。仿真中位姿来自 TF，σ_配准 由多视角一致性检验来估计。

## 6. ROS 接口（阶段五教训已纳入）

- **节点**：`hydromining_robot/scripts/wall_perception_node.py`。按标准生命周期实现：configure 时创建资源，cleanup / shutdown 时释放；由 launch 中的生命周期事件驱动状态转换，节点不自己调用 configure / activate。
- **Action** `AssessRegion.action`（评估是需要较长时间、要有反馈、可能被取消的任务，所以用 Action 而不是 Service）：
  - Goal：区域中心、D、h、p、k；视点列表（关节角）；每个视点的采集帧数和等待策略；是否设为新的基线。
  - Feedback：已完成视点数、当前覆盖率、F_low 和 F_high。
  - Result：判决结果、F_low、F_high、覆盖率、Δd 统计、V ± σ_V、m、区域外意外变化告警（面积、最大退缩）、状态图快照路径。V 和 m 供阶段七计算比能耗（单位去除体积消耗的能量），这是文献二用来评价破岩效率的指标。
- **消息** `CoalWallState.msg`：带字段名的多层栅格（墙面坐标系位姿、分辨率、宽高、层名数组、float32 数据），层包括 depth、sigma、count、coverage、normal_x/y/z、delta、significant。`grid_map` 未安装，所以使用自定义消息。
- **QoS**：传感器输入用 BEST_EFFORT、depth 1；状态输出用 RELIABLE、depth 10，状态图使用 TRANSIENT_LOCAL。
- **其他约束**：
  - 喷嘴和相机位置一律从 TF 查询，不硬编码偏移；
  - 跨模块的时间常数集中写在参数文件中；
  - 状态机写成显式的类，转换受约束，并有单元测试；
  - 共享状态的读写都加锁。

## 9. 阶段五遗留的设计问题（阶段六、七开发时需要注意，本阶段不主动重构阶段五）

1. 喷射接口是 Service，不是 Action。阶段六新增的接口一律用 Action。
2. 喷射是先算完再"播放"，凹坑在喷射结束后才出现。阶段六只在喷射结束后观测；"喷射过程中观测"需要等阶段七改造之后再做。
3. 阶段五的生命周期节点名不副实。阶段六的节点按标准实现，不照搬。
4. 效果指令是按下标读写的字符串协议。阶段六不复用这种方式。
5. Gazebo 煤壁替换会让模型短暂消失。阶段六采集时以 `SprayStatus` 进入 IDLE 并确认网格之后的帧为准，替换期间的帧丢弃。
6. 喷嘴相对 TCP 的 0.05 m 偏移是硬编码的。阶段六一律从 TF 获取。
7. 干扰强度未标定，high 档只影响约 1.5% 的点。阶段六的指标在这种弱干扰下可能虚高，需要在正交表中单独报告各档位的结果，不能只给平均值。

## 11. 参考文献要点

- **Measurement and optimization of coal mass removal rate by high-flow water jet cutting with controlled movement paths (Measurement, 2024, 10.1016/j.measurement.2024.116174)**：
  - 正交试验，因素为靶距 1.0–1.75 m、压力 12–20 MPa、水平移动速度 5–15 mm/s、竖向摆动速度 2–10 mm/s，试件 150 mm 立方体；
  - 质量去除量通过试验前后称重得到，没有做三维形貌测量；
  - 破坏形态包括局部破碎、V 形槽、规则切槽、分层剥落形成新表面；
  - 回归模型只有约 60% 的数据误差小于 25%。

  对本阶段的启示：
  - 输出 m = ρ_c·V，与论文的质量指标和模型公式⑰对接；
  - 喷射前后配准只用稳定区域，以应对分层剥落造成的大面积退缩；
  - 用正交设计组织评估场景；
  - 结果存在明显离散，说明判决必须带不确定性，不能只看点估计。
- **Theoretical and experimental investigation on fracture response of coal impacted by high-velocity water jet (Energy Reports, 2021, 10.1016/j.egyr.2021.05.029)**：
  - 应力波理论加实验。试验条件：喷嘴 1.2 mm、靶距 20 mm、冲击 30 s、射流速度 100–245 m/s，煤样为 100 mm 立方体。
  - 煤存在**阈值速度**（约 100–141 m/s），低于阈值几乎不去除材料；超过阈值后形成破碎坑，周围伴有径向和环向裂纹；速度更高时（≥ 200 m/s）煤样沿层理劈裂，甚至整体破坏；去除体积和破碎面积都是先增后减，在 200 m/s 附近达到最大；比能耗先降后升。
  - 破碎坑体积用**填砂称重法**间接测量；损伤面积用图像二值化加 `regionprops` 统计。

  对本阶段的启示：
  - "真实破坏区域"限定为几何去除，裂纹和损伤区列为适用边界（第 1 节）；
  - 增加作业区域外的意外变化告警，应对劈裂和剥落这类不连续变化（第 5 节）；
  - 输出体积和质量，供阶段七计算比能耗；
  - 文献中坑体积是用独立的物理方法测得的。本阶段对应的做法是：感知估计的体积只和仿真真值比较，不和求解器内部的中间量比较。
  - 尺度差异：文献是毫米级喷嘴、厘米级靶距的单次冲击，与本项目约 0.8 m 靶距的工况不同，数值结论不能直接套用。
  - **阶段四遗留（不在本阶段处理）**：按文献一给出的 v = 44.7√P，20 MPa 对应约 200 m/s，已高于煤的阈值速度；但当前的 R_c(P, s) 没有阈值，也没有劈裂机制。这一点记入阶段四参数标定的遗留项。
- 开源参考：Open3D（采用）、py4dgeo M3C2-EP（采用）、wavemap（官方只有 ROS1 接口，推迟到阶段七再评估）、nvblox（依赖 CUDA 和 Isaac ROS，Jazzy 兼容性未核实，暂不采用）。

## 12. 煤矿环境要求（用户 2026-10-26 补充）

目标环境：**低可见度、粉尘污染重、光照昏暗**。阶段五只模拟了喷射产生的局部水雾和粉尘（约 1.5% 的点受影响），不能代表矿井背景环境，需要单独建模。

### 12.1 对传感器的影响与处理原则

| 因素 | 对传感器的影响 | 本阶段处理 |
|---|---|---|
| 昏暗 | 被动 RGB 几乎不可用；主动红外深度相机和 LiDAR 基本不受影响 | **几何估计以深度相机和 LiDAR 为主，RGB 不进入判决链路**，仅作可选辅助（可见度足够时用于可视化）。Gazebo 的深度渲染与光照无关，所以"昏暗"对 RGB 通过世界光照预设实现，对深度不额外叠加 |
| 背景粉尘 | 光束衰减（Beer–Lambert，透过率 exp(−βz)）、后向散射产生近处假点、远处回波丢失，测距噪声随距离增大 | 在 `sensor_model` 中增加**软件层**环境退化模型，由单一参数"能见度 V（m）"驱动：β ≈ 3.912/V；按透过率给出距离相关的丢点概率与噪声放大，并在近距产生散射假点。必须在报告中说明这是软件叠加，且参数未经实测标定 |
| 喷射水雾 | 沿用阶段五的原生粒子 | 与背景粉尘叠加；两者分开统计 |

### 12.2 环境预设

新增因素"环境"：`clean`（能见度 ∞，光照正常）、`dim_dust_light`（V=8 m）、`dim_dust_heavy`（V=3 m）、`dim_dust_extreme`（V=1.5 m）。能见度数值为**工程假设**，用于压力测试感知算法的退化曲线，不代表某个具体矿井；用户如有实测能见度数据，替换即可。

### 12.3 对验收与算法的影响

- 6.0：确认 Harmonic 中是否可直接使用 world 级雾（`<scene>` 或相机原生选项）；若不支持或对 gpu_lidar 无效，则全部走软件层。结论写入 6.0 记录。
- 6.2 干扰剔除要同时处理"喷射粒子"和"背景粉尘假点"；评估时分别给出精确率和召回率。
- 6.3、6.5：正交表中把原来的"传感器噪声"因素扩展为"传感器噪声 × 环境预设"。**判决必须随可见度变差而更多地转为"证据不足"，而不是更多地错判为"达到"**；错判为"达到"的比例 ≤ 5% 这一指标在所有环境预设下都要满足，否则视为不通过。
- 额外产出**退化曲线**：覆盖率、表面误差、判决正确率和"证据不足"比例随能见度 V 的变化，供阶段七决定近距观测或补视点。
- 极端预设下若深度相机在 1.0 m 靶距以外几乎无回波，属于有效结论（说明必须近距观测），不通过调参掩盖。
