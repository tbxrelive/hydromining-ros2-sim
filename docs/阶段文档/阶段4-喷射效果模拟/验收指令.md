## ⚠️ 注意事项

### 不要在 VSCode 终端运行完整测试

**原因**: 
- 计算量大（131,072 体素 × 50步演化）
- VSCode 终端实时渲染会卡死

**解决**: 
- ✅ 使用快速测试（`test_phase4_integration_mini.py`）
- ✅ 或后台运行完整测试（`nohup ... &`）

详见：[05-VSCode卡死问题解决方案.md](./05-VSCode卡死问题解决方案.md)

## 💡 快速验收一键脚本

```bash
#!/bin/bash
# 一键运行所有验收测试

cd ~/SCI/hydromining_ws
source .venv_stage4/bin/activate

echo "=========================================="
echo "阶段4 快速验收测试"
echo "=========================================="

echo ""
echo "[1/3] 单元测试..."
python3 test_scripts/test_phase4_1_complete.py
if [ $? -ne 0 ]; then
    echo "❌ 单元测试失败"
    exit 1
fi

echo ""
echo "[2/3] 几何转换测试..."
python3 src/hydromining_sim/scripts/algorithms/mesh_converter.py
if [ $? -ne 0 ]; then
    echo "❌ 几何转换测试失败"
    exit 1
fi

echo ""
echo "[3/3] 快速集成测试..."
python3 test_scripts/test_phase4_integration_mini.py
if [ $? -ne 0 ]; then
    echo "❌ 集成测试失败"
    exit 1
fi

echo ""
echo "=========================================="
echo "✅ 阶段4 所有测试通过！"
echo "=========================================="
```

保存为 `test_scripts/run_phase4_acceptance.sh`，然后：

```bash

./test_scripts/run_phase4_acceptance.sh
```
