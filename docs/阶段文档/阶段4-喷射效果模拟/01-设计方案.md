## 二、破煤物理模型

### 2.1 模型假设

1. **作用区域**：喷射形成椭球形破坏区
   - 主轴：喷射方向
   - 半径：与压力和作用时间相关

2. **破坏强度**：距离衰减
   - 中心区域：完全破坏（顶点移除）
   - 边缘区域：部分破坏（顶点位移）

3. **角度效应**：入射角影响
   - 垂直入射：最大破坏
   - 掠射：破坏减弱

4. **煤体强度**：空间随机变化
   - 使用 Perlin Noise 生成强度场
   - 强度高的区域更难破坏

### 2.2 数学模型

#### 输入参数

```python
class SprayParams:
    position: np.ndarray       # 喷射起点 (x, y, z) [m]
    direction: np.ndarray      # 喷射方向（单位向量）
    pressure: float            # 压力 [MPa]
    duration: float            # 作用时间 [s]
    nozzle_diameter: float     # 喷嘴直径 [mm]
```

#### 破坏区域半径

$$
R_{eff} = k_1 \cdot P^{0.5} \cdot t^{0.3} \cdot d^{0.2}
$$

其中：
- $P$: 压力 [MPa]
- $t$: 作用时间 [s]
- $d$: 喷嘴直径 [mm]
- $k_1$: 经验系数（默认 0.5）

#### 距离衰减函数

$$
f_{dist}(r) = \max(0, 1 - (r / R_{eff})^2)
$$

其中 $r$ 是顶点到喷射轴线的距离。

#### 角度衰减函数

$$
f_{angle}(\theta) = \cos(\theta)^2
$$

其中 $\theta$ 是表面法线与喷射方向的夹角。

#### 综合破坏强度

$$
I = f_{dist}(r) \cdot f_{angle}(\theta) \cdot \frac{1}{S(x,y,z)}
$$

其中 $S(x,y,z)$ 是煤体强度场（Perlin Noise，范围 [0.5, 1.5]）。

#### 顶点去除判据

- $I > 0.8$：完全移除顶点
- $0.3 < I \leq 0.8$：顶点沿法线方向位移 $\Delta = I \cdot R_{eff} \cdot 0.1$
- $I \leq 0.3$：保持不变

## 三、Mesh 更新策略

### 3.1 Mesh 数据结构

使用 **trimesh** 库处理 Mesh：

```python
import trimesh

mesh = trimesh.load('coal_wall.obj')
# mesh.vertices: (N, 3) ndarray
# mesh.faces: (M, 3) ndarray (顶点索引)
# mesh.vertex_normals: (N, 3) ndarray
```

### 3.2 更新流程

1. **加载 Mesh**
   ```python
   mesh = trimesh.load('coal_wall_original.obj')
   ```

2. **计算破坏强度**
   ```python
   intensities = coal_breaking_model.compute_intensity(
       vertices=mesh.vertices,
       normals=mesh.vertex_normals,
       spray_params=params
   )
   ```

3. **筛选顶点**
   ```python
   # 移除 I > 0.8 的顶点
   keep_mask = intensities <= 0.8
   new_vertices = mesh.vertices[keep_mask]
   
   # 位移 0.3 < I <= 0.8 的顶点
   displace_mask = (intensities > 0.3) & (intensities <= 0.8)
   displacement = intensities[displace_mask] * R_eff * 0.1
   new_vertices[displace_mask] += mesh.vertex_normals[displace_mask] * displacement
   ```

4. **重建面片**
   ```python
   # 移除包含被删除顶点的面
   face_mask = np.all(np.isin(mesh.faces, np.where(keep_mask)[0]), axis=1)
   new_faces = mesh.faces[face_mask]
   
   # 重新索引顶点
   vertex_map = {old_idx: new_idx for new_idx, old_idx in enumerate(np.where(keep_mask)[0])}
   new_faces = np.vectorize(vertex_map.get)(new_faces)
   ```

5. **创建新 Mesh**
   ```python
   new_mesh = trimesh.Trimesh(vertices=new_vertices, faces=new_faces)
   new_mesh.export('coal_wall_sprayed.obj')
   ```

### 3.3 性能优化

**问题**：大规模 Mesh（~10万顶点）更新耗时

**优化策略**：
1. **空间索引**：使用 KD-Tree 加速邻近顶点查询
2. **局部更新**：只处理 AABB 包围盒内的顶点
3. **并行计算**：NumPy 向量化操作

```python
# AABB 包围盒
spray_center = position + direction * R_eff / 2
aabb_min = spray_center - R_eff * 1.5
aabb_max = spray_center + R_eff * 1.5

# 筛选局部顶点
in_bbox = np.all((mesh.vertices >= aabb_min) & (mesh.vertices <= aabb_max), axis=1)
local_vertices = mesh.vertices[in_bbox]

# 只计算局部顶点的强度
local_intensities = compute_intensity(local_vertices, ...)
```

## 四、Gazebo 模型热更新

### 4.1 问题分析

**挑战**：Gazebo 运行时重新加载模型的 Mesh

**Gazebo Harmonic 支持的方案**：
1. ~~动态修改 SDF（不支持 Mesh 变更）~~
2. **删除旧模型 + 插入新模型**（可行）
3. ~~使用 Gazebo Plugin 动态修改碰撞体（复杂）~~

### 4.2 推荐方案：模型重载

#### 实现步骤

1. **删除旧模型**
   ```python
   from gz.transport import Node
   
   node = Node()
   req = node.request('/world/default/remove', timeout=1000)
   req.set_data('name: "coal_wall"')
   ```

2. **更新 Mesh 文件**
   ```python
   new_mesh.export('models/coal_wall/meshes/coal_wall.obj')
   ```

3. **插入新模型**
   ```python
   req = node.request('/world/default/create', timeout=1000)
   req.set_data(sdf_string)
   ```

#### SDF 模板

```xml
<sdf version="1.9">
  <model name="coal_wall">
    <pose>0 0 0 0 0 0</pose>
    <static>true</static>
    <link name="link">
      <visual name="visual">
        <geometry>
          <mesh>
            <uri>model://coal_wall/meshes/coal_wall.obj</uri>
          </mesh>
        </geometry>
      </visual>
      <collision name="collision">
        <geometry>
          <mesh>
            <uri>model://coal_wall/meshes/coal_wall.obj</uri>
          </mesh>
        </geometry>
      </collision>
    </link>
  </model>
</sdf>
```

### 4.3 备选方案：离线更新

如果热更新不稳定：
1. 喷射后暂停仿真
2. 更新 Mesh 文件
3. 用户手动重启 Gazebo

（不推荐，影响用户体验）

### 5.2 节点实现

**文件**: `src/hydromining_sim/scripts/spray_controller_node.py`

```python
import rclpy
from rclpy.node import Node
from hydromining_sim.srv import SprayCoal
from algorithms.coal_breaking_model import CoalBreakingModel
from algorithms.mesh_updater import MeshUpdater

class SprayControllerNode(Node):
    def __init__(self):
        super().__init__('spray_controller')
        self.srv = self.create_service(
            SprayCoal, 
            'spray_coal', 
            self.handle_spray
        )
        self.breaking_model = CoalBreakingModel()
        self.mesh_updater = MeshUpdater()
        self.get_logger().info('SprayController 已启动')

    def handle_spray(self, request, response):
        start_time = self.get_clock().now()
        
        try:
            # 1. 应用破煤模型
            result = self.breaking_model.apply_spray(
                position=[request.position.x, 
                          request.position.y, 
                          request.position.z],
                direction=[request.direction.x, 
                           request.direction.y, 
                           request.direction.z],
                pressure=request.pressure,
                duration=request.duration,
                nozzle_diameter=request.nozzle_diameter,
                random_seed=request.random_seed if request.random_seed > 0 else None
            )
            
            # 2. 更新 Mesh
            self.mesh_updater.update_coal_wall(result['new_mesh'])
            
            # 3. 重载 Gazebo 模型
            self.mesh_updater.reload_in_gazebo()
            
            # 4. 返回结果
            response.success = True
            response.message = '喷射效果已应用'
            response.volume_removed = result['volume_removed']
            response.vertices_removed = result['vertices_removed']
            response.processing_time = (self.get_clock().now() - start_time).nanoseconds / 1e9
            
        except Exception as e:
            response.success = False
            response.message = f'错误: {str(e)}'
            self.get_logger().error(f'喷射失败: {e}')
        
        return response
```

## 七、参数调优

### 7.1 关键参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| $k_1$ | 0.5 | [0.3, 1.0] | 破坏半径系数 |
| 完全破坏阈值 | 0.8 | [0.7, 0.9] | $I$ 超过此值移除顶点 |
| 部分破坏阈值 | 0.3 | [0.2, 0.5] | $I$ 低于此值不变 |
| 强度场范围 | [0.5, 1.5] | - | 煤体强度的随机变化 |

### 7.2 调优实验

**目标**：找到视觉上合理的参数组合

**实验方案**：
1. 固定压力 10 MPa，扫描 $k_1 \in [0.3, 0.5, 0.7, 1.0]$
2. 固定 $k_1 = 0.5$，扫描压力 $P \in [5, 10, 15, 20]$ MPa
3. 固定其他参数，扫描入射角 $\theta \in [0°, 30°, 60°, 90°]$

**评估指标**：
- 破坏体积（应与压力正相关）
- 破坏形状（椭球形，主轴沿喷射方向）
- 边缘过渡（平滑，不应有突变）
