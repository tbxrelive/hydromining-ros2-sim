### 🔧 关键参数调整（根因诊断后修复）

**问题**：初始测试去除体积为 0

**根因诊断**（按 AGENTS.md 分层诊断流程）：
1. ❌ 冲蚀系数 `k = 1e-5` 过小 → 冲蚀速度仅 4.5e-5 m/s
2. ❌ 演化参数不足：`dt=0.01, n_steps=1` → φ变化量仅 0.013 m（不足1个体素）

**修复方案**：
- ✅ `DefaultErosionKernel.k`: `1e-5` → `1e-3`（增大100倍）
- ✅ `LevelSetEvolver.dt`: `0.01` → `0.5`（增大50倍）  
- ✅ 演化步数: `1步` → `50步`（模拟5秒喷射持续时间）

**效果验证**：
```
冲蚀速度:  4.5e-5 m/s → 4.5e-3 m/s  ✅
φ变化量:   0.013 m   → 0.360 m     ✅ (约4个体素)
去除体积:  0 m³      → 0.007 m³    ✅
```
