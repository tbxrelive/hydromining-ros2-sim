**Gazebo 重载实现** （关键部分）：
```python
import subprocess

def reload_in_gazebo(self, mesh_path):
    """重新加载 Gazebo 中的煤壁模型"""
    # 1. 删除旧模型
    subprocess.run([
        'gz', 'service', '-s', '/world/default/remove',
        '--reqtype', 'gz.msgs.Entity',
        '--reptype', 'gz.msgs.Boolean',
        '--timeout', '1000',
        '--req', 'name: "coal_wall", type: 2'
    ])
    
    # 2. 等待删除完成
    time.sleep(0.5)
    
    # 3. 插入新模型
    sdf_content = self._generate_sdf(mesh_path)
    subprocess.run([
        'gz', 'service', '-s', '/world/default/create',
        '--reqtype', 'gz.msgs.EntityFactory',
        '--reptype', 'gz.msgs.Boolean',
        '--timeout', '1000',
        '--req', sdf_content
    ])
```

**CMakeLists.txt 安装**：

  DESTINATION lib/${PROJECT_NAME}
)

       results/pressure_${pressure}.obj
    
    # 恢复原始 Mesh
    cp src/hydromining_sim/models/coal_wall/meshes/coal_wall_original.obj \
       src/hydromining_sim/models/coal_wall/meshes/coal_wall.obj

kill $NODE_PID $GAZEBO_PID

## 九、常见问题

### Q1: trimesh 导入 .obj 失败

**原因**: .obj 文件格式不完整（缺少法线/纹理坐标）

**解决**:
```python
mesh = trimesh.load('coal_wall.obj', process=False)
# 重新计算法线
mesh.vertex_normals
```

### Q2: Gazebo 模型重载失败

**原因**: 模型名称冲突或 SDF 格式错误

**解决**:
```bash
# 检查 Gazebo 服务
gz service -l | grep world

# 手动测试删除
gz service -s /world/default/remove \
  --reqtype gz.msgs.Entity \
  --reptype gz.msgs.Boolean \
  --timeout 1000 \
  --req 'name: "coal_wall", type: 2'
```

### Q3: 破坏区域太大/太小

**原因**: 参数 $k_1$ 不合适

**解决**: 在 `coal_breaking_model.py` 中调整：
```python
R_eff = 0.3 * pressure**0.5 * duration**0.3  # k1=0.3（减小）
R_eff = 0.7 * pressure**0.5 * duration**0.3  # k1=0.7（增大）
```
