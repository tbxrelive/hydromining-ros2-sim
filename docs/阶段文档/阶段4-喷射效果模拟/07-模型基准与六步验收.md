# 模型基准与六步验收

**来源**：维护者于 2026-10-26 本次对话明确给出的公式①—⑲与验收要求。本文是当前模型基准，不是代码已经实现或物理验证通过的证明。

## 模型定义

模型名称：**局部冲蚀速度驱动的三维煤壁退缩模型**。

范围：局部材料去除、近似正入射；参数尚未完成标定。裂纹扩展、大块失稳剥落、长期喷射破坏极限、煤体空间随机性及一般斜入射响应，不属于本版本已经验证的内容。

按维护者给出的编号：

1. 动作输入为 p(t)、d(t)、P(t)、g(t)，其中 ||d||=1，g∈{0,1}。位置和方向来自喷嘴实际位姿。
2. 初始 φ 为到初始煤体边界的真实符号距离：煤体内部为负，外部为正。
3. Γ(t)={x:φ=0}，Ω(t)={x:φ≤0}。
4. s_c(t)=inf{s>0:φ(p+s d,t)≤0}，使用当前剩余煤体的中心射线首次命中；无交点时本步不去除。
5. x_c(t)=p(t)+s_c(t)d(t)。
6. r(x,t)=||(I−ddᵀ)(x−p)||。
7. χ=g·I_exposed·I[dᵀ(x−p)>0]；I_exposed 表示表面朝向喷嘴且未被其他实体遮挡，不能用“位于喷嘴前方”替代，也不是已标定的入射角衰减。
8. F(ξ)=(1−ξ^(3/2))^6，0≤ξ<1；ξ≥1 时为0。
9. v_e(x,t)=χ(x,t)·R_c(P(t),s_c(t))·F(r(x,t)/b(P(t),s_c(t)))。
10. R_c(P,s)=(K/2)ρ_w u_m³(P,s)。程序优先标定和调用 R_c、b；没有独立射流速度数据时，不同时反算 K 和 u_m。
11. ∂φ/∂t=ṽ_e||∇φ||；ṽ_e 是表面速度向窄带的延拓，近似正入射下 v_e 作为向煤体内部的法向退缩速度。
12. φ^(k+1)=φ^k+Δt·ṽ_e^k||∇φ^k||。使用迎风空间离散及相应稳定时间步；内部为负，因此正号对应去除。演化时间须与实际喷射时间一致。
13. O_q^k=I[φ_q^k≤0]。
14. ΔV_k=Σ_q(O_q^k−O_q^(k+1))ΔV_q。
15. V_removed(T)=Σ_q(O_q^0−O_q^T)ΔV_q。
16. 固定煤体密度下 m_removed=ρ_c V_removed。
17. 整次喷射平均质量去除率 G_hat(T)=m_removed(T)/T。
18. 标定参数表 Θ={R_c(P_α,s_β),b(P_α,s_β)}_(α,β)。
19. 在 Θ>0 下最小化 Σ_j[w_m((m_hat_j−m_j)/m_ref)²+w_h((h_hat_j−h_j)/h_ref)²+w_W((W_hat_j−W_j)/W_ref)²]，权重非负。

量纲：v_e、R_c、u_m 为 m/s，b 为 m，K 为 m³/J，ρ_w 与 ρ_c 为 kg/m³。

公式⑨的三维径向形式是项目基于文献结构的工程改写，不能称为论文原式；公式⑪—⑫也应作为项目几何演化方案单独验证。临时经验核参数不能称为已标定参数。

## 六步最终验收（维护者原要求）

1. 展示初始煤壁，并保存一帧喷射前点云。
2. 固定机械臂，触发一次喷射。
3. 喷射结束后更新煤壁，展示凹坑，输出最大深度和去除体积。
4. 保存喷射后点云，确认传感器观测到了凹坑。
5. 再喷射一次，展示累计变化。
6. 重置煤壁，用相同参数重做，检查结果是否一致。

验收解释：第4步必须证明传感器数据中出现相应几何变化，仅有 OBJ 或 Gazebo 渲染变化不够。第5步从首次喷射后的剩余煤体继续演化；第6步恢复同一初始煤体与算法状态后重放同一动作。数值比较容差、深度/宽度的测量方向和方法、点云比较方法仍需在后续测试设计中明确，本次没有擅自指定阈值。
