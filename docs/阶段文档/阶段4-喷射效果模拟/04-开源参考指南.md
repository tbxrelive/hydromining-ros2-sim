import trimesh

### 1.2 距离场处理：SciPy + scikit-image

#### A. 距离变换

**库**: `scipy.ndimage.distance_transform_edt`

```python
from scipy.ndimage import distance_transform_edt

# 对二值掩码计算欧氏距离变换
binary_mask = ...  # (nx, ny, nz)

# 外部距离
distance_out = distance_transform_edt(~binary_mask)

# 内部距离
distance_in = distance_transform_edt(binary_mask)

# 符号距离 = 内部为负，外部为正
signed_distance = distance_in.astype(float) - distance_out.astype(float)
```

**参考**: 
- https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.distance_transform_edt.html

#### B. 梯度计算

**库**: `numpy.gradient` 或 `scipy.ndimage.sobel`

```python
import numpy as np
from scipy.ndimage import sobel

# 方法1: NumPy梯度（简单）
grad_phi = np.gradient(phi, axis=(0, 1, 2))  # 返回 (3, nx, ny, nz)
grad_norm = np.linalg.norm(grad_phi, axis=0)  # (nx, ny, nz)

# 方法2: Sobel算子（平滑，推荐用于Level Set）
grad_x = sobel(phi, axis=0)
grad_y = sobel(phi, axis=1)
grad_z = sobel(phi, axis=2)
grad_norm = np.sqrt(grad_x**2 + grad_y**2 + grad_z**2)
```

**参考**:
- https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.sobel.html

### 2.1 Level Set 框架

**可参考**: scikit-image 的 Level Set 实现

**文件**: https://github.com/scikit-image/scikit-image/blob/main/skimage/segmentation/_level_set.py

**学习内容**:
- 梯度计算方法
- 时间步长自适应
- 收敛性检查

**为什么要自写**:
- ❌ scikit-image 的Level Set用于图像分割，不适合我们的冲蚀模型
- ✅ 我们需要实现 v_e * ||∇φ|| 的特定形式

**自写框架**:

```python
class LevelSetEvolver:
    def evolve_step(self, phi, v_e, dt):
        """
        φ^(k+1) = φ^k + Δt * v_e * ||∇φ||
        """
        grad_phi = compute_gradient(phi)
        grad_norm = np.linalg.norm(grad_phi, axis=0)
        phi_new = phi + dt * v_e * grad_norm
        return phi_new
```

### 2.2 冲蚀核函数

**用户公式**:
$$F(\xi) = \begin{cases} (1-\xi^{3/2})^6, & 0 \leq \xi < 1 \\ 0, & \xi \geq 1 \end{cases}$$

**完全自写** (无开源参考):

```python
class ErosionKernel:
    @staticmethod
    def kernel_F(xi):
        """
        冲蚀径向核函数
        
        Args:
            xi: r / b (归一化径向距离) [0, ∞)
        
        Returns:
            F(xi) ∈ [0, 1]
        """
        return np.where(xi < 1, (1 - xi**(3/2))**6, 0)
```

**原因**: 这是特定于水射流冲蚀的模型，文献来源是用户的三篇SCI论文

## 四、完整用法示例

### 4.1 SDF 初始化流程

```python
import numpy as np
import trimesh
from scipy.ndimage import distance_transform_edt

def initialize_sdf_from_mesh(mesh_path, voxel_resolution):
    """
    从Mesh初始化符号距离场
    
    步骤:
    1. 加载Mesh (trimesh)
    2. 获取AABB
    3. 创建体素网格
    4. 计算每个体素到Mesh的距离 (trimesh)
    
    返回: phi (nx, ny, nz)
    """
    # 加载Mesh
    mesh = trimesh.load(mesh_path, process=False)
    
    # 获取AABB
    bounds = mesh.bounds  # [[xmin, ymin, zmin], [xmax, ymax, zmax]]
    
    # 创建体素网格
    nx, ny, nz = voxel_resolution
    origin = bounds[0]
    
    # 计算体素坐标
    x = np.linspace(bounds[0][0], bounds[1][0], nx)
    y = np.linspace(bounds[0][1], bounds[1][1], ny)
    z = np.linspace(bounds[0][2], bounds[1][2], nz)
    X, Y, Z = np.meshgrid(x, y, z, indexing='ij')
    
    # 查询点: (nx*ny*nz, 3)
    query_points = np.stack([X.ravel(), Y.ravel(), Z.ravel()], axis=1)
    
    # 计算符号距离 (trimesh)
    signed_distances = trimesh.proximity.signed_distance(mesh, query_points)
    
    # 重塑为体素网格
    phi = signed_distances.reshape((nx, ny, nz))
    
    return phi, origin, (x[1] - x[0])  # spacing
```

### 4.2 Level Set 演化

```python
from scipy.ndimage import sobel

def level_set_step(phi, v_e, dt):
    """
    单步Level Set演化
    
    公式: φ^(k+1) = φ^k + Δt * v_e * ||∇φ||
    """
    # 计算梯度
    grad_x = sobel(phi, axis=0)
    grad_y = sobel(phi, axis=1)
    grad_z = sobel(phi, axis=2)
    
    # 梯度模
    grad_norm = np.sqrt(grad_x**2 + grad_y**2 + grad_z**2)
    
    # 避免除以零
    grad_norm = np.maximum(grad_norm, 1e-8)
    
    # Level Set演化
    phi_new = phi + dt * v_e * grad_norm
    
    return phi_new
```

### 4.3 Mesh 生成

```python
import pymcubes
import trimesh

def voxel_to_mesh(phi, spacing, origin):
    """
    从体素网格生成Mesh
    
    使用Marching Cubes
    """
    # Marching Cubes
    vertices, faces = pymcubes.marching_cubes(phi, 0)
    
    # 转换到世界坐标
    vertices = vertices * spacing + origin
    
    # 创建trimesh对象
    mesh = trimesh.Trimesh(vertices=vertices, faces=faces)
    
    # 平滑法线
    mesh.smooth()
    
    # 导出
    mesh.export('coal_wall_new.obj')
    
    return mesh
```
