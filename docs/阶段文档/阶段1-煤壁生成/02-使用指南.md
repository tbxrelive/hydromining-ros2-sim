# 煤壁生成工具使用指南

## 概述

本工具用于生成具有真实凹凸几何的倾斜煤壁网格，用于 Gazebo 仿真。

## 目录结构

```
hydromining_ws/
├── venv/                          # Python 虚拟环境
├── assets/
│   └── walls/
│       ├── presets.yaml           # 预设配置
│       └── *.obj                  # 生成的网格备份
├── src/hydromining_sim/
│   ├── scripts/
│   │   ├── generate_coal_wall.py        # 核心生成脚本
│   │   ├── generate_from_preset.py      # 使用预设配置
│   │   └── rebuild_coal_wall.sh         # 快速重建脚本
│   ├── models/coal_wall/
│   │   ├── model.config
│   │   ├── model.sdf
│   │   └── meshes/
│   │       └── coal_wall.obj      # 当前使用的网格
│   └── worlds/
│       └── coal_wall_v02.sdf      # 世界文件
└── setup_env.sh                   # 环境设置脚本
```

## 快速开始

### 1. 激活环境

```bash
cd /home/star/SCI/hydromining_ws
source venv/bin/activate
source setup_env.sh
```

### 2. 生成煤壁（三种方式）

#### 方式 1：使用预设配置（推荐）

```bash
cd src/hydromining_sim/scripts
python generate_from_preset.py default
```

可用预设：
- `default` - 默认配置（中等粗糙度，20度倾斜）
- `smooth` - 平滑煤壁（用于测试基础功能）
- `rough` - 高粗糙度（挑战性场景）
- `steep` - 陡倾斜（60度）
- `large` - 大尺寸煤壁（用于多点作业）
- `thin` - 薄煤层

#### 方式 2：自定义参数

```bash
python generate_coal_wall.py \
  --width 3.0 \
  --height 3.0 \
  --thickness 0.4 \
  --tilt 20.0 \
  --roughness 0.12 \
  --resolution 80 \
  --seed 42 \
  --output ../models/coal_wall/meshes/coal_wall.obj
```

#### 方式 3：使用快速重建脚本

```bash
./rebuild_coal_wall.sh --roughness 0.2 --seed 99
```

### 3. 启动 Gazebo 查看

```bash
cd /home/star/SCI/hydromining_ws
source setup_env.sh
gz sim src/hydromining_sim/worlds/coal_wall_v02.sdf
```

## 参数说明

| 参数 | 单位 | 默认值 | 说明 |
|------|------|--------|------|
| `--width` | m | 3.0 | 煤壁宽度 |
| `--height` | m | 3.0 | 煤壁高度 |
| `--thickness` | m | 0.4 | 煤壁厚度 |
| `--tilt` | 度 | 20.0 | 倾斜角度（0=垂直，90=水平） |
| `--roughness` | m | 0.12 | 表面粗糙度（凹凸振幅） |
| `--resolution` | - | 80 | 网格分辨率（越高越精细，但文件越大） |
| `--seed` | - | 42 | 随机种子（相同种子生成相同几何） |

## 验收标准

启动 Gazebo 后，应看到：

✓ **灰色地面**：平整的灰色平面作为基准  
✓ **倾斜煤壁**：深灰色煤体，明显倾斜  
✓ **真实凹凸**：正面有连续起伏、局部凸起与凹陷  
✓ **可见厚度**：转动视角能看到侧面和厚度  
✓ **真实几何**：凹凸来自实际几何，不是贴图  
✓ **碰撞检测**：煤壁可参与碰撞（后续加入机械臂后验证）

## 故障排查

### 问题 1：Gazebo 找不到模型

**症状**：错误信息 `Unable to find uri[model://coal_wall]`

**解决**：
```bash
source setup_env.sh
echo $GZ_SIM_RESOURCE_PATH  # 应包含 .../hydromining_sim/models
```

### 问题 2：网格不显示或显示异常

**症状**：煤壁位置为空或显示为红色/粉色

**解决**：
1. 检查网格文件是否存在：
   ```bash
   ls -lh src/hydromining_sim/models/coal_wall/meshes/coal_wall.obj
   ```
2. 重新生成网格：
   ```bash
   cd src/hydromining_sim/scripts
   python generate_from_preset.py default
   ```

### 问题 3：虚拟环境未激活

**症状**：`ModuleNotFoundError: No module named 'trimesh'`

**解决**：
```bash
source venv/bin/activate
```

## 技术细节

### 生成算法

1. **表面生成**：使用 Perlin Noise 生成自然起伏的高度场
2. **多尺度叠加**：三个八度（octaves）叠加，产生大尺度起伏 + 中等细节 + 小尺度纹理
3. **厚度构建**：复制前表面并沿法向偏移，生成后表面
4. **侧壁连接**：沿四条边界生成四边形面片连接前后表面
5. **倾斜应用**：绕 Y 轴旋转整个网格

### 依赖库

- `perlin-numpy` - Perlin Noise 生成
- `trimesh` - 网格操作和导出
- `numpy` - 数值计算
- `scipy` - 插值和缩放
- `matplotlib` - 预览图生成（可选）
