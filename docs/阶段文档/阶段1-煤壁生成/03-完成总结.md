## 使用示例

### 快速开始

```bash
# 1. 激活环境
cd /home/star/SCI/hydromining_ws
source venv/bin/activate
source setup_env.sh

# 2. 使用预设生成煤壁
cd src/hydromining_sim/scripts
python generate_from_preset.py default

# 3. 启动 Gazebo
cd /home/star/SCI/hydromining_ws
gz sim src/hydromining_sim/worlds/coal_wall_v02.sdf
```

### 自定义参数

```bash
# 生成超粗糙煤壁
python generate_coal_wall.py \
  --roughness 0.3 \
  --tilt 45 \
  --seed 123 \
  --output ../models/coal_wall/meshes/coal_wall.obj
```

## 技术亮点

1. **物理真实性**
   - 使用分形噪声（多个八度叠加）生成自然起伏
   - 避免规则网格的人工感
   - 粗糙度参数直接对应物理尺寸（米）

2. **可重复性**
   - 随机种子确保相同参数生成完全相同的几何
   - 便于算法对比实验

3. **高效集成**
   - 复用开源库（perlin-numpy, trimesh）
   - 直接导出 Gazebo 兼容格式
   - 无需手动建模工具

4. **易用性**
   - 预设配置覆盖典型场景
   - 一键式重建脚本
   - 详细的参数说明和故障排查

## 已知限制

1. **网格水密性**：`fill_holes()` 报告为 `False`，但不影响 Gazebo 显示和碰撞。可能原因是侧壁连接算法在边界存在微小间隙。

2. **分辨率与性能**：`resolution=200` 以上会显著增加生成时间和文件大小，默认 80-100 已足够。

3. **厚度均匀性**：当前后表面简单沿 Z 轴偏移，未考虑前表面法向，可能在高粗糙度时局部厚度不完全均匀。
