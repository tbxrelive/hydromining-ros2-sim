## 二、技术方案

### 2.1 Panda 机器人集成

**来源**：`moveit_resources` 或系统安装的 `moveit_resources_panda_description`

**所需文件**：
```
panda_robot/
├── meshes/
│   ├── visual/        # 来自 moveit_resources
│   └── collision/     # 来自 moveit_resources
└── urdf/
    ├── panda.urdf.xacro           # 主文件
    ├── panda_gazebo.xacro         # Gazebo 扩展
    └── panda.ros2_control.xacro   # ros2_control 配置
```

**调整点**：
- 命名空间改为 `hydromining`
- 基座位置适配煤壁场景（距离煤壁 2-3m）
- 添加 gz_ros2_control 插件

### 2.2 水枪末端执行器设计

**设计原则**：
- 简化几何（圆柱体 + 圆锥喷嘴）
- 合理质量（2-3 kg）
- 明确 TCP（Tool Center Point）= 喷嘴尖端

**URDF 结构**：
```xml
water_gun.urdf.xacro
  ├─ water_gun_body_link
  │   ├─ visual: 圆柱体（直径 0.08m, 长 0.3m）
  │   ├─ collision: 简化圆柱
  │   └─ inertial: 质量 2.5 kg
  │
  ├─ nozzle_link (连接到 body)
  │   ├─ visual: 圆锥体
  │   └─ inertial: 质量 0.2 kg
  │
  ├─ tcp_link (虚拟，喷射参考点)
  │   └─ origin: xyz="0 0 0.05"  # 喷嘴尖端前 5cm
  │
  └─ camera_mount_link (传感器安装点)
      └─ origin: xyz="0.1 0 0"  # 侧面偏移
```

**材质**：
- 深灰色金属（RGB 0.3, 0.3, 0.35）
- 喷嘴黄色标识（RGB 0.9, 0.8, 0.1）

### 2.3 传感器配置（参考 spraying 项目）

**传感器布局**：

1. **末端相机**（RGB-D）
   - 类型：Intel RealSense D435i 仿真
   - 位置：水枪侧面，朝向煤壁
   - 话题：`/camera/color/image_raw`, `/camera/depth/image_rect_raw`

2. **点云传感器**（激光雷达）
   - 类型：Velodyne VLP-16 或 Ouster OS1
   - 位置：机器人底座或固定支架
   - 话题：`/lidar/points`

3. **TF 树**：
   ```
   world
     └─ robot_base_link
         └─ panda_link0
             └─ ... (Panda 关节链)
                 └─ panda_hand
                     └─ water_gun_body
                         ├─ nozzle
                         │   └─ tcp
                         └─ camera_link
   ```

### 2.4 ros2_control 配置

**控制器**：
- `joint_trajectory_controller`（位置控制）
- `joint_state_broadcaster`（状态发布）

**配置文件**（`ros2_control.yaml`）：
```yaml
controller_manager:
  ros__parameters:
    update_rate: 100
    
    joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
    
    panda_arm_controller:
      type: joint_trajectory_controller/JointTrajectoryController

panda_arm_controller:
  ros__parameters:
    joints:
      - panda_joint1
      - panda_joint2
      - panda_joint3
      - panda_joint4
      - panda_joint5
      - panda_joint6
      - panda_joint7
    
    command_interfaces:
      - position
    
    state_interfaces:
      - position
      - velocity
    
    state_publish_rate: 50.0
    action_monitor_rate: 20.0
```

### 2.6 Launch 文件架构

**`robot_simulation.launch.py`**（主启动文件）：
```python
def generate_launch_description():
    return LaunchDescription([
        # 1. 启动 Gazebo 服务器
        IncludeLaunchDescription(
            GazeboLaunch('gz_sim.launch.py'),
            launch_arguments={'world': world_file}.items()
        ),
        
        # 2. 加载机器人描述到 robot_state_publisher
        Node(
            package='robot_state_publisher',
            executable='robot_state_publisher',
            parameters=[{'robot_description': robot_description}]
        ),
        
        # 3. 生成机器人到 Gazebo
        Node(
            package='ros_gz_sim',
            executable='create',
            arguments=['-topic', 'robot_description']
        ),
        
        # 4. 启动 ros2_control
        Node(
            package='controller_manager',
            executable='spawner',
            arguments=['joint_state_broadcaster']
        ),
        Node(
            package='controller_manager',
            executable='spawner',
            arguments=['panda_arm_controller']
        ),
        
        # 5. ROS-Gazebo 桥接
        Node(
            package='ros_gz_bridge',
            executable='parameter_bridge',
            arguments=[
                '/camera/image@sensor_msgs/msg/Image@gz.msgs.Image',
                '/lidar/points@sensor_msgs/msg/PointCloud2@gz.msgs.PointCloudPacked'
            ]
        ),
        
        # 6. 启动 RViz（可选）
        Node(
            package='rviz2',
            executable='rviz2',
            arguments=['-d', rviz_config_file]
        )
    ])
```

### Step 5: 集成组合模型

创建 `src/hydromining_robot/urdf/panda_with_water_gun.urdf.xacro`：
```xml
<robot name="panda_water_gun">
  <!-- 包含 Panda -->
  <xacro:include filename="$(find hydromining_robot)/models/panda_robot/urdf/panda.urdf.xacro"/>
  
  <!-- 包含水枪 -->
  <xacro:include filename="$(find hydromining_robot)/models/water_gun/urdf/water_gun.urdf.xacro"/>
  
  <!-- 连接水枪到 Panda 法兰 -->
  <joint name="panda_hand_to_water_gun" type="fixed">
    <parent link="panda_hand"/>
    <child link="water_gun_body"/>
    <origin xyz="0 0 0.1" rpy="0 0 0"/>
  </joint>
  
  <!-- 包含传感器 -->
  <xacro:include filename="$(find hydromining_robot)/urdf/sensors.urdf.xacro"/>
</robot>
```
