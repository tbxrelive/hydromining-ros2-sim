### 5. 创建组合 URDF

创建 `src/hydromining_robot/urdf/panda_with_water_gun.urdf.xacro`：

```xml
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="panda_water_gun">
  
  <!-- 包含 Panda -->
  <xacro:include filename="$(find hydromining_robot)/models/panda_robot/urdf/panda.urdf.xacro"/>
  
  <!-- 实例化 Panda -->
  <xacro:panda_arm name="panda" 
                    connected_to="world" 
                    safety_limits="false"/>
  
  <!-- 包含水枪 -->
  <xacro:include filename="$(find hydromining_robot)/models/water_gun/urdf/water_gun.urdf.xacro"/>
  
  <!-- 连接水枪到 Panda 法兰 -->
  <joint name="panda_hand_to_water_gun" type="fixed">
    <parent link="panda_hand"/>
    <child link="water_gun_body"/>

  <!-- 包含传感器 -->
```

### 6. 创建 ros2_control 配置

创建 `src/hydromining_robot/config/ros2_control.yaml`：

```yaml
controller_manager:
  ros__parameters:
    update_rate: 100
    
    joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
    
    panda_arm_controller:
      type: joint_trajectory_controller/JointTrajectoryController

panda_arm_controller:
  ros__parameters:
    joints:
      - panda_joint1
      - panda_joint2
      - panda_joint3
      - panda_joint4
      - panda_joint5
      - panda_joint6
      - panda_joint7
    
    command_interfaces:
      - position
    
    state_interfaces:
      - position
      - velocity
    
    state_publish_rate: 50.0
    action_monitor_rate: 20.0
    
    constraints:
      stopped_velocity_tolerance: 0.01
      goal_time: 0.0
```

### 9. 创建简单的 Launch 文件

创建 `src/hydromining_robot/launch/robot_simulation.launch.py`：

```python
#!/usr/bin/env python3
import os
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, IncludeLaunchDescription
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.substitutions import FindPackageShare
from ament_index_python.packages import get_package_share_directory

def generate_launch_description():
    # 包路径
    pkg_hydromining_robot = get_package_share_directory('hydromining_robot')
    pkg_hydromining_sim = get_package_share_directory('hydromining_sim')
    
    # 文件路径
    urdf_file = os.path.join(pkg_hydromining_robot, 'urdf', 'panda_with_water_gun.urdf.xacro')
    world_file = os.path.join(pkg_hydromining_sim, 'worlds', 'coal_wall_v02.sdf')
    ros2_control_config = os.path.join(pkg_hydromining_robot, 'config', 'ros2_control.yaml')
    
    # 处理 URDF
    import xacro
    robot_description_raw = xacro.process_file(urdf_file).toxml()
    
    return LaunchDescription([
        # 启动 Gazebo
        IncludeLaunchDescription(
            PathJoinSubstitution([
                FindPackageShare('ros_gz_sim'),
                'launch',
                'gz_sim.launch.py'
            ]),
            launch_arguments={'gz_args': ['-r ', world_file]}.items()
        ),
        
        # Robot State Publisher
        Node(
            package='robot_state_publisher',
            executable='robot_state_publisher',
            name='robot_state_publisher',
            output='screen',
            parameters=[{'robot_description': robot_description_raw}]
        ),
        
        # 生成机器人到 Gazebo
        Node(
            package='ros_gz_sim',
            executable='create',
            arguments=['-topic', 'robot_description',
                      '-name', 'panda_water_gun'],
            output='screen'
        ),
        
        # 启动控制器
        Node(
            package='controller_manager',
            executable='spawner',
            arguments=['joint_state_broadcaster'],
            output='screen'
        ),
        
        Node(
            package='controller_manager',
            executable='spawner',
            arguments=['panda_arm_controller'],
            output='screen'
        ),
    ])
```

## 故障排查

### 问题 1：找不到 Panda 文件

**解决**：
```bash
sudo apt install ros-jazzy-moveit-resources-panda-description
```

### 问题 2：xacro 解析失败

**检查**：URDF 中的路径是否正确
```bash
xacro src/hydromining_robot/urdf/panda_with_water_gun.urdf.xacro
```

### 问题 3：Gazebo 无法加载机器人

**检查**：
1. ros2_control 插件是否正确配置
2. `GZ_SIM_RESOURCE_PATH` 是否包含模型路径
