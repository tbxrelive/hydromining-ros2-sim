## 🔍 问题分析（Systematic Debugging）

### 第 1 层：信息收集

**关键发现**：
1. 代码依赖 `open3d` 和 `sensor_msgs_py.point_cloud2`
2. `open3d` 未安装在 ROS 2 环境中（仅存在于虚拟环境 `venv_test`）
3. `sensor_msgs_py.point_cloud2.read_points()` 对点云字段格式敏感

### 第 2 层：根因定位

**根本原因**：
- ✗ **设计缺陷**：点云采集节点使用了外部依赖 `open3d`（不是 ROS 2 标准依赖）
- ✗ **格式脆弱性**：`sensor_msgs_py.point_cloud2.read_points()` 在处理 Gazebo LiDAR 输出时，字段匹配逻辑不健壮

**触发条件**：
- Gazebo GPU LiDAR 插件输出的 PointCloud2 消息包含额外字段（如 `intensity`, `ring` 等）
- `sensor_msgs_py` 的 `read_points()` 尝试构建 NumPy structured array 时，dtype 与实际字段不匹配

### 第 3 层：解决方案设计

**方案对比**：

| 方案 | 优点 | 缺点 | 是否采用 |
|------|------|------|---------|
| 安装 `open3d` 到系统 | 快速 | 污染系统环境，--break-system-packages | ❌ |
| 使用 `pcl_ros` | ROS 标准库 | Jazzy 版本可能不稳定 | ❌ |
| 手动解析 PointCloud2 | 无外部依赖，完全控制 | 代码稍长 | ✅ **采用** |

**选定方案**：
- 移除 `open3d` 依赖
- 手动从 PointCloud2.data 二进制数据中解析 x, y, z 坐标
- 直接写入 PCD 格式（ASCII）

```python
def save_as_pcd(self, cloud_msg, filename):
    """保存点云为 PCD 格式（不依赖 Open3D）"""
    import struct
    
    # 解析点云数据
    points = []
    point_step = cloud_msg.point_step
    data = cloud_msg.data
    
    # 查找 x, y, z 字段的偏移量
    x_offset = None
    y_offset = None
    z_offset = None
    
    for field in cloud_msg.fields:
        if field.name == 'x':
            x_offset = field.offset
        elif field.name == 'y':
            y_offset = field.offset
        elif field.name == 'z':
            z_offset = field.offset
    
    if x_offset is None or y_offset is None or z_offset is None:
        raise ValueError(f"点云缺少 x/y/z 字段，实际字段: {[f.name for f in cloud_msg.fields]}")
    
    # 提取点云坐标
    for i in range(0, len(data), point_step):
        # 从二进制数据中解析 float32
        x = struct.unpack_from('f', data, i + x_offset)[0]
        y = struct.unpack_from('f', data, i + y_offset)[0]
        z = struct.unpack_from('f', data, i + z_offset)[0]
        
        # 跳过 NaN 和 Inf
        if np.isfinite(x) and np.isfinite(y) and np.isfinite(z):
            points.append([x, y, z])
    
    if len(points) == 0:
        raise ValueError("点云为空（所有点都是 NaN）")
    
    points_array = np.array(points, dtype=np.float32)
    
    # 写入 PCD 文件（ASCII 格式）
    with open(filename, 'w') as f:
        f.write("# .PCD v0.7 - Point Cloud Data file format\n")
        f.write("VERSION 0.7\n")
        f.write("FIELDS x y z\n")
        f.write("SIZE 4 4 4\n")
        f.write("TYPE F F F\n")
        f.write("COUNT 1 1 1\n")
        f.write(f"WIDTH {len(points_array)}\n")
        f.write("HEIGHT 1\n")
        f.write("VIEWPOINT 0 0 0 1 0 0 0\n")
        f.write(f"POINTS {len(points_array)}\n")
        f.write("DATA ascii\n")
        
        for point in points_array:
            f.write(f"{point[0]} {point[1]} {point[2]}\n")
    
    self.get_logger().info(f"保存了 {len(points_array)} 个点到 {filename}")
```

**优点**：
1. ✅ 无外部依赖（仅使用 Python 标准库 `struct`）
2. ✅ 字段解析健壮（直接读取 offset，不依赖字段顺序）
3. ✅ 兼容任何包含 x/y/z 的 PointCloud2 消息
