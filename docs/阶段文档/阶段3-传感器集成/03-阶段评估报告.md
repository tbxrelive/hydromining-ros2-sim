### 2. 点云数据解析

**问题**：
- `sensor_msgs/PointCloud2` 是二进制格式
- 需要正确解析 `PointField` 和 `data` 字段

**解决方案**：
```python
import struct

def pointcloud2_to_xyz_array(self, cloud_msg):
    """手动解析 PointCloud2 消息"""
    # 1. 找到 x, y, z 字段的偏移量
    x_offset = next(f.offset for f in cloud_msg.fields if f.name == 'x')
    y_offset = next(f.offset for f in cloud_msg.fields if f.name == 'y')
    z_offset = next(f.offset for f in cloud_msg.fields if f.name == 'z')
    
    # 2. 按 point_step 分割二进制数据
    point_step = cloud_msg.point_step
    data = cloud_msg.data
    
    # 3. 提取每个点的 x, y, z
    for i in range(0, len(data), point_step):
        x = struct.unpack('f', data[i+x_offset:i+x_offset+4])[0]
        y = struct.unpack('f', data[i+y_offset:i+y_offset+4])[0]
        z = struct.unpack('f', data[i+z_offset:i+z_offset+4])[0]
        if not math.isnan(x):
            points.append([x, y, z])
```

**经验教训**：
- ✅ 不依赖 `sensor_msgs_py`（在 Jazzy 中可能缺失）
- ✅ 手动解析确保兼容性
- ✅ 过滤 NaN 值（GPU LiDAR 可能产生无效点）
