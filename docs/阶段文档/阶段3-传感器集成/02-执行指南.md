## 四、问题排查

### 问题 1：`test_observation.py` 报错 "Action Server 不可用"

**现象**：
```
[observation_test]: 等待 Action Server...
（卡住很久）
```

**解决**：
1. 检查控制器是否正常加载：
   ```bash
   ros2 control list_controllers
   # 应显示 panda_arm_controller [active]
   ```

2. 检查 action 话题：
   ```bash
   ros2 action list
   # 应包含 /panda_arm_controller/follow_joint_trajectory
   ```

3. 如果 action 名称不对，修改 `test_observation.py` 中的：
   ```python
   '/panda_arm_controller/follow_joint_trajectory'
   # 改为实际的 action 名称
   ```

### 问题 2：点云采集服务调用失败 "无可用点云数据"

**原因**：激光雷达话题没有数据

**解决**：
```bash
# 检查激光雷达话题
ros2 topic list | grep lidar
ros2 topic hz /hydromining/lidar/points
ros2 topic echo /hydromining/lidar/points --once
```

如果没有数据，检查 `sensors.urdf.xacro` 中的传感器配置。

### 问题 3：TF 变换查找失败

**现象**：
```
[pointcloud_capture]: 采集失败: Could not transform ...
```

**解决**：
```bash
# 查看 TF 树
ros2 run tf2_tools view_frames
evince frames.pdf

# 检查是否有 world → lidar_link 的完整链
```

### 问题 4：配准 fitness 很低（< 0.3）

**原因**：观测位姿重叠区域不足

**解决**：
1. 减小 `VIEWPOINT_B` 的角度差（从 30° 改为 15°）
2. 调整机器人到煤壁的距离（修改初始位置）
3. 在 RViz 中可视化点云确认覆盖范围
