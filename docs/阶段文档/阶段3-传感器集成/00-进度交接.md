### 4.1 Bridge 话题映射修复

**问题**：`rgbd_camera` 插件在 Gazebo 中发布的话题名与 bridge 配置不匹配。

**Gazebo 实际发布的话题**（`gz topic -l`）：
- `/hydromining/camera/image` — RGB 图像
- `/hydromining/camera/depth_image` — 深度图像
- `/hydromining/camera/camera_info` — 相机参数
- `/hydromining/camera/points` — 点云

**原 bridge 配置（错误）**：
```python
'/hydromining/camera/color/image_raw@...',  # ❌ 不存在
'/hydromining/camera/depth/image_rect_raw@...',  # ❌ 不存在
```

**修复后的 bridge 配置**：
```python
# 使用 Gazebo 实际话题 + ROS 2 remapping
arguments=[
    '/hydromining/camera/image@sensor_msgs/msg/Image@gz.msgs.Image',
    '/hydromining/camera/depth_image@sensor_msgs/msg/Image@gz.msgs.Image',
    '/hydromining/camera/camera_info@sensor_msgs/msg/CameraInfo@gz.msgs.CameraInfo',
    '/hydromining/camera/points@sensor_msgs/msg/PointCloud2@gz.msgs.PointCloudPacked',
    ...
],
remappings=[
    ('/hydromining/camera/image', '/hydromining/camera/color/image_raw'),
    ('/hydromining/camera/depth_image', '/hydromining/camera/depth/image_rect_raw'),
    ('/hydromining/camera/camera_info', '/hydromining/camera/color/camera_info'),
    ('/hydromining/camera/points', '/hydromining/camera/depth/points'),
]
```

**修改文件**：`src/hydromining_robot/launch/robot_simulation.launch.py`

### 4.2 添加 gui 参数支持

**目的**：允许无 GUI 模式启动仿真，避免 GUI 堆积占用资源。

**修改内容**：
```python
# 添加参数声明
declare_gui = DeclareLaunchArgument(
    'gui',
    default_value='true',
    description='Start Gazebo GUI if true'
)

# 修改 Gazebo 启动参数
gz_args_with_gui = PythonExpression([
    "'", '-r ', world_file, "' if '", gui, "' == 'true' else '", '-r -s ', world_file, "'"
])
```

**使用方法**：
```bash
# 有 GUI（默认）
ros2 launch hydromining_robot robot_simulation.launch.py

# 无 GUI（测试用）
ros2 launch hydromining_robot robot_simulation.launch.py gui:=false
```
