## 问题诊断过程

### 原始问题
```
Package 'hydromining_robot' not found
```

### 根本原因（依次发现）

1. **环境变量未正确 source** ❌
   - 初步诊断，但不是根本原因

2. **hydromining_sim 不是 ROS 2 包** ✅

   - Launch 文件依赖该包但无法找到

   - 使用 `launch.conditions.IfCondition` 但未导入
   - 导致 `NameError: name 'launch' is not defined`

4. **venv 干扰 colcon 包识别** ⚠️
   - colcon 扫描到 `venv/lib/python3.12/site-packages/numpy`
   - 警告但不影响主流程

## 技术要点记录

### ROS 2 包的最小要求

1. **package.xml** - 包元数据
2. **CMakeLists.txt** 或 **setup.py** - 构建配置
3. 正确的目录结构

### Launch 文件的常见错误

1. **导入不完整** - 使用前必须导入
2. **路径错误** - FindPackageShare 需要正确的包名
3. **参数类型错误** - LaunchConfiguration 返回 Substitution

### colcon 构建的注意事项

1. **venv 应该在工作空间外** - 避免扫描干扰
2. **清理后重建** - 使用 `--cmake-clean-cache`
3. **并行构建** - 使用 `--parallel-workers N`
