### 问题 C：控制器未就绪

**症状**：`[WARN] Waiting for action server...`

**解决**：
```bash

# 2. 应该看到：
#    joint_trajectory_controller [joint_trajectory_controller/JointTrajectoryController]
#    joint_state_broadcaster     [joint_state_broadcaster/JointStateBroadcaster]

# 3. 如果缺失，等待更长时间（最多 30 秒）
```

### 问题 D：机械臂不移动

**症状**：测试脚本运行但机械臂静止

**可能原因**：
1. 控制器未加载 → 检查终端 1 的日志
2. 目标位置不可达 → MoveIt 会打印警告
3. 碰撞检测阻止运动 → 查看 Gazebo 的碰撞可视化

**调试命令**：
```bash
# 查看活动话题
ros2 topic list | grep joint

# 查看关节状态
ros2 topic echo /joint_states --once

# 查看控制命令
ros2 topic echo /joint_trajectory_controller/joint_trajectory --once
```
