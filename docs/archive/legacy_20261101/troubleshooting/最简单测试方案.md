## 问题确认

你遇到的问题：`source install/setup.bash` 后，ROS 2 仍然只在 `/opt/ros/jazzy` 中搜索包。

这说明 **install/setup.bash 没有正确扩展环境变量**。

### 方案 3：从头开始（如果方案 1/2 都失败）

#### 步骤 1：完全清理

```bash

```

**重要**：在新的终端窗口执行（避免环境污染）

## 如果仍然失败

### 可能的根本原因

1. **虚拟环境干扰**
   - 如果你在 Python venv 中，退出：`deactivate`
   - venv 可能修改了 PATH 和其他环境变量

2. **Bash 配置文件干扰**
   - 检查 `~/.bashrc` 是否有冲突的 ROS 设置
   - 临时测试：`bash --noprofile --norc`

3. **colcon 版本问题**
   - 检查版本：`colcon version-check`
   - 更新：`sudo apt update && sudo apt install python3-colcon-common-extensions`

4. **权限问题**
   - 检查：`ls -la install/`
   - 修复：`chmod -R u+rwX install/`
