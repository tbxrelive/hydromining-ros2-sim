## 新的文档命名规则

1. **所有文档使用中文命名**
2. **阶段文档按数字编号**：`01-`, `02-`, `03-` 等
3. **文件名简洁明了**：说明内容而非格式
4. **避免大写和特殊字符**：使用中文、数字、连字符

## 文档内容规范

### 标题格式

```markdown
# 阶段X：XXX功能 - YYY文档类型

## 一、概述
## 二、技术方案
## 三、实现细节
## 四、验收标准
## 五、问题记录
```

### 代码块规范

- 使用 `bash` 标记 shell 命令
- 使用 `python` 标记 Python 代码
- 使用 `xml` 标记 URDF/SDF
- 使用 `yaml` 标记配置文件

### 链接规范

- 内部文档：`[文档名](../相对路径.md)`
- 外部资源：`[描述](URL)`
- 代码文件：`[文件名](../../src/路径)`
