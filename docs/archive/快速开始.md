# 水力采煤机器人自主作业仿真系统

## 项目概述

面向急倾斜煤层水力采煤场景，研究机器人在**干扰观测、动态环境、不确定反馈**条件下的自主作业能力。

### 研究内容

| 环节 | 研究问题 | 技术方向 |
|------|---------|---------|
| **感知** | 干扰条件下的煤壁状态可信估计 | 多传感器融合、不确定性量化 |
| **规划** | 主动观测与运动规划 | NBV 规划、信息增益优化 |
| **决策** | 自适应喷射动作选择 | 强化学习、效果预测 |

## 常见问题

### ❌ "Package 'hydromining_robot' not found"

**原因**：在错误的目录或未 source 环境

**解决**：
```bash
cd /home/star/SCI/hydromining_ws  # 确保在根目录
colcon build --packages-select hydromining_robot
source install/setup.bash
```

### ❌ "Unable to find or download file"

**原因**：`GZ_SIM_RESOURCE_PATH` 未设置

**解决**：
```bash
source setup_env.sh
echo $GZ_SIM_RESOURCE_PATH  # 应包含 .../hydromining_sim/models
```

### ❌ 传感器话题无数据

**原因**：仿真未完全启动或桥接失败

**解决**：
1. 等待 10 秒后再检查
2. 查看 ros_gz_bridge 是否运行：`ros2 node list | grep bridge`
3. 检查 Gazebo 是否正常：窗口中是否显示机器人
